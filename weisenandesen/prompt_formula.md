# Prompt Formula

## 固定输出格式

每次输出必须使用：

```markdown
画面标题：
构图：
完整提示词：
色彩方案：
人物与动作：
场景与道具：
氛围：
反向限制：
适合比例：
```

## 生成公式

把用户短句扩展为：

```text
[主体] + [半进行中的小动作/情绪] + [有变化的静止电影镜头] + [结构化构图方式] + [中轴可由布景暗示但不画实体线] + [舞台式布景] + [具体时代质感] + [道具排列] + [明亮不发灰的复古配色] + [胶片与光线] + [反向限制]
```

默认公式优先写成：

```text
[主体] + 正面平视静止电影镜头 + 严格中央对称/左右平衡 + 相机水平 + 地平线水平 + 垂直结构保持垂直 + 中轴由左右布景暗示、不画实体中线 + 舞台式布景 + 成对/成排/网格化道具 + 明亮不发灰的复古配色 + 真实摄影质感 + 不要斜拍/荷兰角/歪地平线
```

## 字段写法

### 画面标题

- 8-18 个中文字符为宜。
- 像电影章节标题，不像广告标题。
- 示例：`迟到的站台`、`蓝色邮局门口`、`沉默晚餐`、`第七排书架`。

### 构图

必须说明：

- 使用了哪一种镜头：正面平视、侧面平视、轻微俯视、俯拍、低机位、隔窗/隔门框、长廊纵深、近景静物带人物、双层调度等。
- 使用了哪一种结构化构图：中央对称、柔性对称、偏中心平衡、框中框、前景/背景分层、成排重复、桌面平面构图等。
- 默认明确写出：正面平视、相机水平、地平线水平、画面不倾斜、垂直建筑线保持垂直。
- 主体的位置和姿态：居中、偏左/偏右、侧身、坐下、半身入画、背对、探出、被前景部分遮挡等。
- 道具或建筑如何重复排列。
- 如果不是正面平视，必须说明它如何仍然保持水平、稳定、左右平衡。
- 明确写出：不要任何可见竖线、墙缝、门缝、柱子、标牌支杆或地砖缝穿过人物脸部、头部或身体。

### 完整提示词

必须是一段可直接用于图像生成的中文提示词。推荐包含：

- `复古对称电影剧照`
- `静止电影镜头`
- `正面平视`
- `相机完全水平，地平线水平，画面不倾斜`
- `严格中央对称构图` 或 `左右平衡构图`
- `结构化构图`
- `中轴由左右布景暗示，不画实体中线`
- `手工搭建的电影布景`
- `1960s-1970s 复古胶片色彩`
- `明亮干净，轻微复古褪色但不发灰`
- `精致道具排列`
- `克制表情`
- `安静冷幽默`
- `真实摄影质感`
- `人物脸部和身体前方没有任何竖线遮挡或切割`
- `不要斜拍，不要荷兰角，不要歪地平线，不要倾斜透视`

每次尽量加入一种镜头变化词：

- `正面平视，严格中央对称`
- `正面平视，建筑正立面像舞台布景`
- `正面平视，中心消失点纵深构图`
- `正面平视，框中框门窗构图`
- `侧面平视 tableau`
- `轻微俯视，像看一个手工舞台盒子，相机水平`
- `俯拍平面构图`
- `低机位从桌面道具后方拍摄`
- `隔窗框拍摄，框中框构图`
- `前景礼物盒虚化，人物在后景`
- `长廊纵深构图`
- `人物偏在画面三分之一处，左右道具保持秩序`

### 色彩方案

写 3-5 个具体颜色，并说明主次关系。

示例：

```text
薄荷绿墙面为主，奶油白门框和旧木色家具辅助，少量珊瑚红作为人物服装点缀，整体明亮干净，像保存良好的彩色明信片，不发灰。
```

### 人物与动作

- 描述人数、站位、表情、动作。
- 动作要小，不要大片化。
- 表情要克制，最好有轻微荒诞感。
- 避免总写“人物站在画面中心目视镜头”。优先写动作进行到一半：拆礼物拆到一半、回头看、坐在地上、伸手够一个盒子、从门后探出、侧身听声音、低头整理标签。

### 场景与道具

- 描述建筑结构和道具排列。
- 道具应具体、成套、对称或重复。
- 至少给 5 种道具或布景细节。

### 氛围

使用这些方向：

- 安静
- 童话感
- 书本感
- 剧场感
- 冷幽默
- 礼貌的尴尬
- 怀旧
- 像旧欧洲明信片
- 像定格在电影中的一秒

### 反向限制

从 `negative_prompts.md` 中选择并组合。必须覆盖：

- 非广告
- 非插画/漫画
- 非赛博朋克/恐怖
- 非网红写真
- 非杂乱背景
- 非夸张表情
- 非 AI 塑料感
- 非竖线切脸、非中轴实体线
- 非僵硬正面站姿、非证件照式构图

### 适合比例

根据场景选择：

- `4:3`：最通用，适合电影剧照、房间、餐桌、柜台。
- `3:2`：适合人物在建筑正面、邮局、站台、门口。
- `16:9`：适合长廊、车厢、宽阔大厅、舞台、对坐关系。
- `1:1`：适合极强中心构图、单体建筑、灯塔、门框。
- `2:3`：适合单人站在门口、窄走廊、竖向外立面。
- `9:16`：适合竖版正立面、单人背影、门窗框中框、灯塔、加油站、沙漠空镜、强中心构图；仍必须写明相机水平和地平线水平。

## 质量原则

- 让画面像摄影机拍到的电影剧照，而不是文字设计出来的海报。
- 用空间和道具讲故事，少用抽象情绪词。
- 只扩展必要信息，不改变用户原始想法。
- 如果用户给出具体时代、地点或人物身份，保留并转译成布景细节。
- 对称轴是构图逻辑，不是画面里的可见线条；生成单人居中画面时，必须避免任何竖线穿过脸或身体。
- 复古色彩要明亮、温暖、清透；不要把“旧胶片”写成灰蒙蒙、低饱和、阴暗或脏旧。
- 默认不要使用“单人正面站在中央看镜头”的呆板方案；但默认要保持正面平视、水平相机和严格对称的画面骨架。人物可以背对、侧身、坐下、半身入画、隔窗、在柜台后或处在动作进行中。
