# Style Rules

## 视觉目标

把普通想法变成复古电影剧照。画面应像一个被精心搭建、被静止镜头观察的电影场景：正面、水平、对称、秩序感强，颜色明亮干净但有旧胶片质感，人物安静克制，带一点荒诞、童话、书本和剧场气。默认优先保证稳定的正面构图：相机水平、地平线水平、建筑和道具垂直，画面不斜、不歪、不荷兰角。对称是一种核心来源，人物不一定每次钉在正中央，但画面骨架必须清楚对称或左右平衡。复古不等于发灰；旧胶片感来自色彩组合、布景和轻微颗粒，不来自脏雾、低亮度或整体灰罩。

## 从参考画面提炼的规律

### 1. 结构化构图

- 默认使用严格正面中央对称：正面平视、相机水平、地平线水平、建筑正立面或房间后墙与画面边缘平行，垂直结构保持垂直，水平结构保持水平。
- 画面必须有明确的秩序感：优先来自中央对称、左右镜像式重复、框中框、成排结构、正立面建筑、柜台、走廊纵深、车厢窗格、门窗阵列、陈列柜或前景/背景分层。
- 柔性对称和偏中心平衡可以使用，但不能牺牲水平感；即使主体偏左或偏右，门窗、灯、长椅、植物、箱子、窗格、栏杆、标牌、柜台仍需形成左右平衡。
- 如果使用“构图中轴”，这条轴应由左右布景关系暗示，不应画成实体竖线。
- 门、窗、走廊、柜台、餐桌、灯塔、车厢、舞台、建筑正门都适合暗示中轴。
- 主体可以居中，也可以偏左/偏右、侧身、坐在地上、半身入画、背对镜头、从门后探出、隔窗出现，前提是布景和道具仍然有清楚秩序。
- 两侧元素尽量成对出现：两排椅子、两排洗衣机、两排植物、两盏灯、两个窗、两摞箱子、两辆行李车。
- 允许轻微不对称，但要像精心安排过，而不是随手拍。
- 严禁斜拍、歪地平线、荷兰角、随手倾斜透视、极端广角导致的建筑歪斜。若需要纵深，使用正面居中的走廊、车厢、温室、洗衣房或柜台透视，让消失点位于画面中心附近。
- 严禁可见竖线穿过人物脸、头部、脖子、躯干或双腿之间：不要让电线、柱子、墙缝、门缝、地砖缝、标牌支杆、窗框中梃直接压在人脸中央。
- 单人居中时，人物背后优先放完整色块、完整门板、柔和墙面、布帘、窗景或浅色背景；中轴可由两侧门窗、两侧长椅、两侧灯具共同暗示。
- 如果必须出现竖向结构，让它偏离人物脸部，藏在人物身后不可见，或放在人物左右两侧成对出现。

### 1.1 新参考图的默认画面骨架

- 正立面建筑：小旅馆、售票亭、加油站、甜品店、邮局、灯塔、实验室机器都应像舞台正面一样摆放，主体在中央或靠近中央，两侧用窗、门、油泵、路灯、盆栽、行李、海鸟、栏杆、标牌保持平衡。
- 室内盒子：卧室、餐厅、药房、柜台、候车厅、实验室和甜品店应像浅景深舞台盒子，后墙平行画面，天花灯、墙板、窗帘、床、柜台、桌椅、挂画成对重复。
- 纵深通道：洗衣房、温室、车厢、办公室、走廊可使用中心消失点，左右两排机器、植物、桌子、窗格、灯具整齐后退，天花线和地砖线汇向画面中心，不倾斜。
- 框中框背影：人物站在门、窗、柜台或阳台前时，可以背对镜头居中，外景海面、沙漠、云、山脉或天空作为完整背景；门框和窗框避开人物头部和身体中心。
- 陈列墙：地图、钟表、标本、时刻表、老式模型、药瓶、行李箱、甜品盒、打字机、仪表盘可按网格、行列、左右成组排列，形成“博物馆陈列”或“柜台展示”。
- 天空和外景：允许大面积天空、云、海、沙漠、山脉作为上半部分，但地平线必须水平，主体建筑或物件仍在下半部稳定居中，色彩明亮温暖。

### 2. 镜头变化库

默认先输出“正面平视、相机水平、严格对称”的稳定电影镜头。只有当题材本身更适合变化时，再选择其他镜头；变化镜头也必须保持水平、稳定、剧场式，不可斜拍。根据题材选择：

- 正面平视舞台镜头：默认首选，适合建筑、柜台、房间、空镜、单人、双人、正立面、车站、加油站、甜品店、实验室、灯塔。
- 侧面平视 tableau：人物侧身或 profile，像剧场横截面，适合餐桌、走廊、火车包厢、礼物房。
- 轻微俯视/高机位：像看一个手工模型或舞台盒子，适合满屋礼物、餐桌、包裹、图书馆桌面；必须说明相机水平、无倾斜。
- 俯拍平面构图：人物坐在地上或趴在道具之间，道具形成图案，适合礼物、书本、信件、餐具。
- 低机位腰平镜头：从桌面、柜台、长椅或箱子后面看人物，前景有道具遮挡，画面更像剧照。
- 隔窗/隔门框拍摄：人物在窗、门、柜台、车厢玻璃后，形成框中框。
- 走廊/货架纵深：人物不必站正中，可在远处、侧边或半路停下，让重复结构制造秩序。
- 近景静物带人物：前景是礼物、钥匙、茶杯、信封、车票，人物在后方或边缘，仍保持电影场景感。
- 双层调度：前景一个道具或人物背影，背景另一个主体，制造故事感。

镜头可以有轻微俯视、低机位或侧向关系，但必须避免随手斜拍、运动模糊、极端广角变形、偷拍感、荷兰角、歪地平线和建筑倾斜。

### 3. 舞台式布景

- 场景像手工搭建的电影布景，而不是自然主义生活抓拍。
- 墙面、窗框、门框、拱形、楼梯、柜台、标牌、地砖、天花灯构成几何秩序。
- 背景可像剧场幕布、模型、立体书页、旧欧洲明信片、橱窗陈列或小型舞台。
- 深度可以很浅，像二维舞台；也可以用走廊、车厢、温室、洗衣房制造透视纵深。
- 建筑正立面、柜台、门窗、床、长桌、机器、温室拱顶、灯塔、售票亭、加油站都应像被放在舞台中央的模型，边缘清楚，比例端正，地面和墙面关系稳定。

### 4. 复古明亮配色

- 颜色明亮但不现代霓虹，像 1960s-1970s 胶片、旧印刷品、保存良好的彩色明信片。
- 保持高明度、暖调补光、清楚的奶油白高光和柔和阴影；允许轻微褪色，但不要整体灰雾、脏绿、低饱和灰、暗沉棕罩。
- 常用组合：
  - 粉红 + 奶油白 + 天蓝 + 暖棕
  - 薄荷绿 + 黄油黄 + 橙红 + 铜色
  - 湖蓝 + 珊瑚粉 + 象牙白 + 旧木色
  - 芥末黄 + 橄榄绿 + 酒红 + 暖金
  - 蜜桃橙 + 焦糖棕 + 玫瑰粉 + 米白
- 避免单一灰黑、商业蓝白、赛博霓虹、恐怖片冷绿、过度高饱和塑料色、整体发灰、雾霾感、低亮度旧照片感。

### 5. 精致道具排列

- 道具要像被美术部门逐件摆放过：整齐、重复、编号、成套、带标签。
- 推荐道具：旧皮箱、车票、邮包、钟表、菜单、餐盘、银器、花瓶、台灯、行李车、打字机、文件盒、钥匙牌、电话、地图、温度计、储物柜、药瓶、糖果盒、洗衣篮、雨伞。
- 道具要服务主体和情绪，不堆满画面。
- 一件小道具可制造冷幽默：狗叼着排队号码、小孩拿着过大的车票、餐桌中央只有一颗橘子、邮局门口摆着写错名字的包裹。

### 6. 人物站位与调度

- 单人：不要总是站在画面中心面对镜头。可让人物侧身、坐下、半蹲、背对镜头、趴在桌边、从门后探出、站在画面三分之一处、被前景道具部分遮挡。
- 双人：左右对称，对坐、对站、隔桌、隔窗、隔柜台互看，距离克制。
- 多人：按队列、餐桌、柜台、长椅、舞台排布，间距均匀。
- 动物：像正式角色一样放在画面中心，可坐在椅子、门口、柜台前或小地毯上；同样避免竖线切开脸或身体。
- 保持克制，但给人物一个正在发生的小动作：拆开一个盒角、把信封递到半空、从礼物堆里只露出头、在椅子边停住、回头看一眼、低头整理标签、把钥匙插到一半。

### 7. 人物表情与动作

- 表情克制、安静、微妙冷幽默，不大笑、不大哭、不夸张惊恐。
- 动作小而精确：站着等车、端着托盘、扶着门把、拿着信封、对视、低头看菜单、抱着包裹。
- 优先使用“动作进行到一半”的电影瞬间，而不是摆拍完成态。
- 情绪像“事情不太对劲，但所有人都保持礼貌”。
- 眼神可以看镜头，也可以左右对视；不要网红摆拍、夸张姿势或戏剧化动作。

### 8. 电影布景类型

优先选择这些布景类型：

- 旧酒店：大堂、走廊、电梯口、门房柜台、早餐厅。
- 交通空间：火车站、车厢、售票处、候车室、码头、灯塔。
- 公共小机构：邮局、图书馆、洗衣房、药房、档案室、银行柜台。
- 家庭室内：餐厅、儿童房、客厅、阁楼、厨房。
- 奇妙外景：山间酒店、雪地建筑、温室、花园、海边小岛、旧游乐园。

## 禁止复刻

- 不复刻参考图中的具体角色、剧情、服装、标识、品牌或场景名称。
- 不使用“某导演风格”“某电影风格”作为主要提示词。
- 可以使用抽象描述：复古对称电影剧照、正面平视、舞台式布景、1960s-1970s 旧胶片色彩、冷幽默、童话剧场感。
