## 景别
从远到近：大远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写。
- 远景全景：交代环境、空间关系、人物在场景中的位置。
- 中景：动作戏主力景别，能看清动作与上半身表情。
- 近景特写：放大情绪、手部动作、关键道具（拔枪、扣扳机、眼神）。
动作戏常用「全景立势 → 中景打斗 → 近景/特写收点」的景别节奏。

## 运镜
- **推（Push in）**：镜头推近，聚焦/施压。
- **拉（Pull out）**：镜头后拉，揭示环境或收尾。
- **摇（Pan / Tilt）**：机位不动，左右摇 / 上下摇。
- **移（Tracking / Truck）**：机位平移跟随。
- **跟（Follow）**：跟拍主体运动（过肩跟拍、贴身跟拍）。
- **升降（Crane / Boom）**：垂直升降。
- **环绕（Arc / Orbit）**：绕主体半圈/整圈，强动感与立体感。
- **手持（Handheld）**：抖动、临场、纪实感。
- **甩镜（Whip pan）**：快速甩动，常用于切镜衔接。
- **变焦（Zoom）**：光学推拉，可配合移动做「滑动变焦/眩晕镜」。
写法：`<景别>·<运镜>`，如「中景·过肩跟拍」「近景·贴身横移」「全景·低角度环绕」。Seedance 用自然语言即可，无需英文术语，但动作要有方向与速度。

## 机位与角度
低角度（仰拍，显力量/压迫）、高角度（俯拍，显渺小/全局）、平视、过肩、第一人称视角、无人机航拍大全景、贴地机位。角度服务情绪：英雄登场多低角度仰拍，绝境多高角度俯压。

## 器材与质感
- 胶片感：仿 IMAX / 35mm / 16mm 胶片摄影机，胶片颗粒，轻微闸门抖动。
- 镜头：变形宽银幕（anamorphic）横向光晕与椭圆焦外、定焦大光圈浅景深、广角畸变。
- 拍摄方式：手持、斯坦尼康稳定跟随、轨道车、肩扛。
- 画质约束：高细节、1080p 质感、运动清晰不拖影（用正向词，别写负向）。

## 色彩与调影
- 调性公式：`<美学/年代> + <主色调与对比> + <胶片或数字质感> + <饱和与对比度>`。
- 常用色调：青橙对比（动作大片）、复古暖橙+海盐蓝（科幻复古）、低饱和冷蓝（悬疑/末日）、高饱和霓虹（赛博朋克）、柔和米褐（文艺/回忆）、黑白高反差（硬派）。
- 质感词：胶片颗粒、低饱和复古滤镜、高对比、暗角、漏光、卤化银质感、数字锐利干净。

## 光线与氛围
自然日光 / 强直射光 / 柔光 / 侧逆光勾边 / 顶光 / 底光（恐怖）/ 实用光源（霓虹、火光、屏幕光、车灯）。明暗关系：高光不过曝、暗部保留细节、明暗过渡自然、营造立体光影。氛围：硝烟、雾气、雨丝、扬尘、漂浮微粒——既造气氛也让运动可见。

## 节奏与时长
- 单条视频建议 5s 或 10s（@24fps）。
- 分镜数量按动作密度：5s 约 2–4 镜，10s 约 4–7 镜。
- 时间区间累加 ≈ 总时长，区间连续不重叠（如 0–2s / 2–3.5s / 3.5–7s / 7–10s）。
- 快节奏动作戏：单镜可短至 0.3–1.5s 的「快切 beat」；抒情/氛围镜可 2–4s 一镜。

## 多镜头衔接
切镜要点（Seedance 多镜头要显式说衔接 + 切后重述场景）：
- 衔接词：无缝切至 / 镜头甩动跟至 / 硬切 / 叠化 / 匹配剪辑（动作匹配）。
- 切到新场景时，重新交代「在哪 + 谁 + 在做什么」，别假设模型记得上一镜。
- 一镜到底（无切换）时，靠运镜把多个 beat 串起来，强调「动作不停、镜头流畅无卡顿」。

## 一致性约束
模型不认负向词，全部写成正向 + 写进全局头：
- 角色一致：同一角色、服装一致、发型不变、配色一致。
- 结构正常：人体/机械结构正常、比例自然、四肢完整。
- 面部稳定：五官清晰、面部稳定、表情自然不扭曲。
- 把「不要崩」「别糊」翻译成「边缘锐利」「主体清晰稳定」。

## 进阶范例

### 范例 A · 科幻一镜到底（10s，对标截图风格）
输入：机器人被重重摔在地，翻滚起身后拔出左轮，连续击杀冲来的丧尸。

```
【视觉基调】
变形宽银幕电影质感，仿 IMAX 胶片摄影机 + Panavision C 系列镜头；全程手持拍摄，动态模糊，轻微手持抖动，保持临场感与紧迫感。

【色彩与调影】
60 年代复古科幻原子朋克美学；复古暖橙 + 海盐蓝高对比色调，胶片颗粒质感，低饱和度复古滤镜；自然日光照明，强直射光，自然光晕；明暗对比强烈，高光不过曝，暗部保留完整细节。

【情绪基调】
画面血腥暴力，战斗节奏紧凑激烈，凸显末日逃亡的惊险追逐，强调速度感与力量感。

【一致性约束】
始终为同一机器人主角，金属机身与配色一致；机械结构正常、比例自然；面部 LED 屏红色愤怒表情清晰稳定不扭曲。

【画面内容】
分镜1 开场入画（0–1.5s） 广角低角度固定镜头：机器人面部 LED 屏亮起红色愤怒表情，重重摔向地面，从画面左侧入画，向前侧滚翻卸力，尘土随翻滚飞溅，滚翻结束瞬间单膝跪地，左手撑地稳住身形，动作流畅无卡顿。
分镜2 备战起势（1.5–3s） 中景·环绕半圈无缝衔接：机器人单膝跪地起身，右手闪电般探向腰间快拔枪套，掏出左轮手枪，拇指顺势扳倒击锤完成待击，枪口瞬间指向前方，视线锁定围堵而来的多只丧尸。
```

### 范例 B · 5s 情绪短镜（非动作）
输入：雨夜，老人独自在公交站台抬头看驶离的末班车。

```
【视觉基调】
电影感数字摄影，定焦浅景深，斯坦尼康稳定缓移，画面克制沉静。

【色彩与调影】
夜雨蓝调低饱和，路灯与车灯暖橙点缀，湿地面高光反射；柔和实用光源照明，暗部保留细节，整体清冷。

【情绪基调】
孤独、怅然、被时间落下的无力感，节奏舒缓。

【一致性约束】
同一名老人，深色外套与帽子一致；面部清晰稳定，神态自然。

【画面内容】
分镜1 抬头望车（0–3s） 中近景·缓慢推进：老人独立于湿亮的公交站台下，雨丝在灯光里斜划，他缓缓抬头，目光追随画面右侧驶离的末班车，眼神里浮起一丝失落。
分镜2 雨中独留（3–5s） 全景·缓缓后拉：镜头后拉，老人被孤零零留在空荡站台，车灯红光在湿地面拉出长长倒影渐渐远去，雨声中只剩他一个剪影。
```
