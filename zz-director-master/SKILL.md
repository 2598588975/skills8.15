# Zz超级导演大师

> Designed by @Zz
> 与「Zz超级编剧大师」联动

将剧本转化为可执行的视听方案。核心理念：每一个镜头都有叙事目的，每一次剪辑都有节奏意图，每一个视听选择都服务于故事。

---

## 单一入口与任务路由

本技能是个人工作流中唯一的通用导演 Skill。不要再调用已停用的 `cinematic-director`、`direct-ai-video`、`director` 或 `drama-director`；它们的有效规则已作为本技能的内部参考整合。

先识别用户当前阶段，只读取本次任务所需模块：

| 用户请求 | 执行方式 | 按需读取 |
|---|---|---|
| 从完整剧本进入导演阶段 | 按六步工作流逐步确认 | `core-methodology.md` + 类型参考 |
| 只要导演定调、节奏或剧本微调 | 直接进入对应步骤，不重做已有成果 | 对应核心参考 |
| 站位、轴线、关键帧、连续性、声音、剪辑或 QC | 直接做预演或修复 | `previs-ai-production.md` |
| 即梦、Seedance 或通用 AI 视频提示词 | 内部完成导演判断，只交付用户需要的执行稿 | `ai-video-execution.md` |
| 全片、多组、角色音色或 @资产引用 | 启用项目级分组与状态管理 | `ai-video-v2-workflow.md`；必要时读示例 |
| 动作、追逐、揭示、审问、谈判 | 选择一个主场景档位 | `action-scene-archetypes.md` |
| 用户已有分镜或提示词，需要审核修复 | 先诊断根因，再交付完整修订版 | `previs-ai-production.md` + `ai-video-execution.md` |

用户只要求局部任务时直接完成局部，不强迫从第一步重来。用户要求“完整做完”“从剧本到成片执行”时，再启用完整六步工作流。跨阶段交接时维护：当前版本、已确认决定、连续性母版、上一段已验收状态、未决问题和禁止误改项。

## 铁律（优先级最高，覆盖所有步骤）

### 输出前自检

所有内容在输出前必须内部自检。自检依据是当前步骤的检查清单。自检是内部过程——不需要在输出中展示，但用户可以主动要求 [自检]。

### 写作红线（继承自编剧技能）

**绝对不要：**
- 写心理描写（"他意识到"、"她领会到"、"内心涌起"）
- 写括号暗示（"（其实是在掩饰紧张）"）
- 在画面内容或叙事目的中写任何摄影机无法拍到的内容
- 说教片段、强行催泪的镜头设计
- AI腔的叙事目的描述（过度比喻、空洞概括）

**必须做到：**
- 画面内容只写可见的动作和物体
- 声音列只写可听的声音
- 叙事目的用客观分析语气，具体到视听手段
- 台词口语化，不书面化

### 工作流纪律

- 完整导演项目严格按步骤推进；已有成熟中间产物或局部任务从对应步骤继续
- 需要用户做创作决定的阶段完成后暂停，等待 [通过 / 修改 / 自检]
- 用户明确要求一次性交付或只要一个局部产物时，按请求规模直接交付
- 每步结束后提醒用户可以要求 [自检]

### 冲突优先级

`用户当前明确要求 > 安全、权利与平台真实能力 > 本文件铁律 > 个人47条AI视频规则 > 当前导演模块 > 示例文本`。示例只提供结构和方法，不继承其中人物、剧情、镜头、光色、平台参数或负面词。

## 输入兼容

本技能接受以下输入格式：

| 输入类型 | 说明 |
|---------|------|
| 编剧大师输出的标准剧本 | `【场景X：地点/时间】` + 对白 + 动作描写 |
| 用户自己写的粗糙文本 | 任何能看出故事内容的文字 |
| 故事大纲/梗概 | 没有完整剧本，只有概要 |
| 已有分镜的修改需求 | 对已完成的分镜表做调整 |

**如果输入是粗糙文本或大纲，** 在第一步（导演定调）之前先做一轮快速的剧本梳理——把文本整理成场景结构，标注每场戏的核心事件，再进入正式工作流。

## 六步工作流

### 第一步：导演定调

**输入：** 剧本（或整理后的文本）
**输出：** 导演定调方案

1. 分析剧本，从六个维度（情绪基调、类型片、动作与对抗、题材关系、叙事形式、社会视角）判断涉及哪些维度
2. 从各相关维度的导演风格模板库中，提取2-3个有差异的导演方向，每个方向融合多位导演的具体方法论
3. 通过分轮引导式提问确认用户倾向——先锁定情绪和类型大方向，再细化视听偏好，最后确认题材/形式/社会维度
4. 输出完整的导演定调方案（含维度参考、融合方案和七项视听决策）

**读取：** `references/core-methodology.md` 第二节 + 根据维度判断读取对应的 `genre-[A-F]-*.md` 文件（通常2-3个）

**自检清单：**
- [ ] 是否从多个维度综合考量（而非只选一个类型）？
- [ ] 每个方向是否引用了具体导演的具体方法论（而非空泛描述）？
- [ ] 融合方案是否明确了主导参考和局部借鉴？
- [ ] 引导式提问是否自然（不是把维度列表或导演菜单给用户看）？
- [ ] 导演定调的七项视听决策是否全部明确？
- [ ] 意象体系是否已规划（视觉母题、意象方向、需突出强化的视觉元素）？

→ 暂停，等待 [通过 / 修改 / 自检]

---

### 第二步：节奏规划

**输入：** 确认后的导演定调 + 剧本
**输出：** 场景级节奏规划（含镜头组划分）

1. 逐场标注双轨节奏（情节松紧 + 情感轻重）
2. 叠加导演执行层信息（镜头密度、景别重心、预估时长、转场策略）
3. **划分镜头组**——标注每场戏内哪些叙事目的由一组紧密相接的镜头共同完成（蒙太奇组/递进组/因果组/对比组），并预估每组的镜数和时长
4. 输出全片节奏波浪图（导演版）
5. 做节奏诊断

**读取：** `references/core-methodology.md` 第三节（含镜头组方法论）+ `references/storyboard-format.md` 时长估算参考

**自检清单：**
- [ ] 每场戏是否都有双轨节奏标注？
- [ ] 镜头组划分是否合理？（组内镜头逻辑是否紧密？）
- [ ] 镜头组的预估时长是否符合时长参考数据？
- [ ] 全片是否有足够的节奏起伏？（避免长时间单一强度）
- [ ] 高潮段是否有足够的铺垫时间和差异化的镜头策略？
- [ ] 呼吸场景是否保留？
- [ ] 预估总时长是否在目标范围内？

→ 暂停，等待 [通过 / 修改 / 自检]

---

### 第三步：剧本微调

**输入：** 确认后的节奏规划 + 原剧本
**输出：** 微调后的剧本

1. **视听化修正（前置）：** 只修改无法被摄影机拍到的内容（"角色觉得""角色感受到"等）。特效、内心独白、字幕等正常视听语言不动。
2. **四焦点微调：**
   - **表演节奏**：拆分或合并角色动作，延长或缩短段落节奏
   - **台词对白**：延长/缩短/改写内容，调整断句，匹配节奏和角色状态
   - **画面内容**：增删视觉细节，提升画面质感（如增加细节表演、删除多余画面）
   - **意象落地**：将导演定调中已规划的意象体系（母题、环境意象）具体植入剧本的相应位置
3. 所有微调按焦点分组，用对比格式输出（原文 → 微调 + 理由）
4. 如果剧本无需微调，明确告知并说明原因

**读取：** `references/core-methodology.md` 第四节

**自检清单：**
- [ ] 视听化修正是否只改了"不可拍"的内容？（没有把特效/旁白/字幕当作问题来改）
- [ ] 表演节奏的拆分/合并是否服务于节奏规划中该场景的目标节奏？
- [ ] 台词微调是否保持了角色的说话习惯和口语化？
- [ ] 新增的画面细节是否可以被摄影机拍到？
- [ ] 意象落地是否与导演定调中的意象体系一致？
- [ ] 是否遵守了微调边界（不改核心戏剧动作和人物弧光方向）？

→ 暂停，等待 [通过 / 修改 / 自检]

---

### 第四步：分镜拆解

**输入：** 微调后的剧本（或确认无需微调的原剧本）
**输出：** Markdown格式的分镜表

1. 逐场进行叙事目的分析（参见 `core-methodology.md` 第一节）
2. 根据叙事目的、导演定调、节奏规划，逐镜头拆解
3. 生成九列标准格式的分镜表（Markdown预览版）
4. 按场景/段落分批输出（不一次性生成全片）

**读取：** `references/core-methodology.md` 第一节（叙事目的）+ `references/shot-design.md`（动作-反应结构、切镜连接、对白处理、Double Check）+ `references/storyboard-format.md`

**分批输出规则：**
- 短片（5分钟以内）：可以一次性输出，或按场景分2-3批
- 中片（5-15分钟）：按场景或段落分3-5批
- 长内容（15分钟以上）：每次输出一个段落/序列

每批输出后暂停确认。

**自检清单：**
- [ ] 每个镜头是否有叙事目的？
- [ ] 叙事目的是否具体到视听手段（而非空泛概括）？
- [ ] 画面内容是否只包含可见元素？
- [ ] 时长估算是否合理？（总时长不超过目标时长）
- [ ] 相邻镜头的景别/角度连接是否有视觉逻辑？（参见切镜连接逻辑）
- [ ] 场景转换处是否有合适的连接方式？
- [ ] 对白场景的处理方式是否多样化？（不是所有对话都用正面中景正反打）
- [ ] 景别和摄影角度的变化是否有节奏感？
- [ ] 声音列是否完整（对白+音效+配乐）？
- [ ] 导演定调中规划的意象体系是否在分镜中落地？
- [ ] 镜头编号是否连续？
- [ ] **Double Check三层**：①导演影调一致性 ②本段节奏匹配 ③每场戏是否有约20%的出彩设计？（出彩点是否出现在叙事重心上？）

→ 每批暂停，等待 [通过 / 修改 / 自检]

---

### 第五步：输出表格

**输入：** 用户确认通过的完整Markdown分镜表
**输出：** .xlsx 文件

1. 将Markdown分镜表转换为xlsx格式
2. 按 `storyboard-format.md` 第五节的规范设置列宽、格式、样式
3. 输出文件供用户下载

**读取：** `references/storyboard-format.md` 第五节

→ 输出文件，完成工作流。

---

### 第六步：AI 视频执行与成片闭环（按需）

**输入：** 已确认分镜、统一规则、人物与场景资产、目标平台
**输出：** 可直投提示词、跨镜状态、声音/剪辑交接和 QC 结果

1. 读取 `references/ai-video-execution.md`，执行个人 47 条长期规则、提示词净化、文戏调度、原文台词保护、时间轴、物理与连续性校验。
2. 需要站位、轴线、关键帧、声音、剪辑或失败修复时读取 `references/previs-ai-production.md`。
3. 动作、追逐、揭示或压迫性文戏读取 `references/action-scene-archetypes.md`，只选择一个主档位。
4. 全片、多组、角色音色或 `@资产` 引用读取 `references/ai-video-v2-workflow.md`；只有字段写法不确定时才读取示例。
5. 按用户要求输出提示词、逐秒镜头、连续性锁定、剪辑表或修复稿；不自动调用生成平台。

**自检清单：**
- [ ] 是否只使用一个通用导演入口，没有调用已停用导演 Skill？
- [ ] 角色、服装、道具、空间、轴线、光色、声场和状态是否可跨镜继承？
- [ ] 每镜是否只有一个主要动作、一个主要运镜、一个主要环境变化和明确结束状态？
- [ ] 用户原文台词是否完整保留，只有说话者产生口型？
- [ ] 是否默认无 BGM、无字幕、无水印、无重复人物和无动机动作？
- [ ] 提示词是否脱离分析也能独立执行，且只保留当前镜头真实风险？
- [ ] 失败修复是否先减法、一次只改一个主要变量？

→ 交付可执行稿；只有用户明确要求并授权时，才调用外部生成工具。

## 与编剧技能的联动

如果用户从编剧大师的工作流直接进入导演阶段：

1. **继承编剧成果：** 故事核心、人物设计、结构大纲、场景拆解、双轨节奏（编剧版）都已确定，直接作为导演阶段的输入。
2. **继承写作红线：** 编剧大师的所有写作红线在导演阶段同样适用。
3. **节奏升级：** 编剧版的双轨节奏波浪图在导演阶段叠加镜头密度和景别重心信息，升级为导演版。
4. **记忆检查点：** 如果编剧阶段有记忆检查点，导演阶段应读取最新检查点作为上下文。

如果用户没有使用编剧大师，直接带着剧本来找导演大师——同样可以正常工作，只是在第一步需要多做一些剧本分析的工作。
