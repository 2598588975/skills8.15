# 8. Prompt生成算法：AI按这6步组装

第1步：识别用户输入里的主体、场景、动作、道具、比例、是否要视频。

第2步：选择一个母题；如果用户给定场景，就把场景映射到最近的母题。

第3步：先写“真实摄影镜头里的具体画面”，不要先堆风格词。

第4步：加入光线逻辑：逆光/侧逆光/阴天散射/雨天湿反光，保证人物关键部位可读。

第5步：加入色彩与质感：低饱和稻田绿、雾蓝灰、奶油白、浅黑位、柔焦、轻DV噪点。

第6步：最后加入负面约束，排除商业写真、强HDR、动漫脸、重噪点和过度锐化。

| prompt_structure:<br>  1_subject_scene: 谁在什么地方<br>  2_action_emotion: 正在做什么，情绪有多轻<br>  3_camera_composition: 机位、景别、前景遮挡、纵深或留白<br>  4_lighting: 逆光/侧逆光/阴天散射/雨天反光<br>  5_color_texture: 低饱和绿、蓝灰空气、奶油白、柔焦、浅黑位、轻DV噪点<br>  6_negative: 排除商业、动漫、HDR、荧光、过锐、重噪点 |

| 强度 | 适用情况 | 写法 |

# 11. 质量检查清单：AI生成后自检

画面是否仍然像真实摄影，而不是插画或海报？

是否有白衬衫/校服/耳机/伞/自行车等青春符号中的至少一个？

绿色是否低饱和、自然、带灰度，而不是荧光绿色？

天空、白衣或湿地面是否有柔和高光，但人物关键动作仍可读？

人物有没有避免直视镜头和夸张表演？

暗部是否是墨绿/青黑/蓝灰，而不是纯黑死掉？

是否保留了柔焦、低对比、轻DV感，而不是过锐数码大片？

负面提示词是否排除了商业写真、动漫脸、HDR、重噪点？

# 13. 最终铁律：AI不能违反

必须像真实摄影，不像概念插画、漫画或商业海报。

白衬衫是最高频视觉锚点；稻田绿、雾蓝灰、墨绿暗部是环境底色。

逆光可以让天空发白，但人物脸、手和关键道具不能糊掉。

情绪要轻，不要演得太满；等待、追逐、听歌、仰望都要像自然发生。

允许柔焦、轻微颗粒、运动虚化和手持感，但禁止明显低清晰度、脏噪点和AI塑料感。

用户要求新场景时，不要照搬稻田；要把该场景转译成同一套光影、色彩、质感和情绪。
