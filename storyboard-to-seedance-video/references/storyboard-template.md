# GPT Image 2 Storyboard Template

Use this as the reusable stage-1 template. Keep the placeholders open for the user to define.

```text
Create a raw cinematic storyboard focused on extreme physical action / expressive motion / staged visual progression. Use reference image for the character.

[ASPECT RATIO] storyboard sheet, [PANEL COUNT] cinematic panels.
The storyboard drawings should be [DRAWING STYLE].
Keep the artwork [ROUGHNESS / DETAIL LEVEL].

Director-board geometry lock:
- scene axis: [CHARACTER-TO-CHARACTER / LINE-OF-TRAVEL / SUBJECT-TO-OBJECT AXIS]
- approved camera zone: [ONE SIDE OF AXIS, DESCRIBED FROM A PLAN VIEW]
- screen positions at start: [CHARACTER / OBJECT SCREEN-LEFT, CENTER, SCREEN-RIGHT]
- facing and eyelines: [WHO FACES OR LOOKS TOWARD WHICH TARGET]
- travel direction: [LEFT-TO-RIGHT / RIGHT-TO-LEFT / DEPTH DIRECTION]
- prop ownership and contact: [WHO HOLDS / TOUCHES / RELEASES WHAT]
- legal axis change, if any: [NONE / VISIBLE CAMERA CROSS / NEUTRAL-AXIS SHOT / CHARACTER MOVEMENT REFORMS AXIS]

Start directly in action. Do not begin with a calm stance, preparation shot or slow introduction.

A [CHARACTER TYPE] performs a [CHOREOGRAPHY OR MOTION TYPE] routine inside [ENVIRONMENT].
The motion should feel [PRIMARY MOTION QUALITIES].

Every panel must contain visible movement and strong body momentum. Avoid static standing poses.

For every panel, preserve the approved camera zone and record a readable start position -> movement path -> end position. Keep screen direction and eyelines consistent across cuts. If the axis changes, show the crossing or re-formation inside a dedicated panel; never jump to the opposite side invisibly.

Action progression:
1. [opening action already in motion]
2. [second beat]
3. [third beat]
...
[final panel]. [ending pose while preserving end-state rule]

Add selective [ELEMENT / VFX TYPE] effects as storyboard accents.
The effects should feel [EFFECT DISCIPLINE].

Element progression:
- early panels: [subtle reactions]
- middle panels: [stronger environmental response]
- late panels: [high-intensity effects]
- final panel: [peak combined effect]

Use cinematic camerawork:
[CAMERA LANGUAGE LIST]

Keep the environment minimal and atmospheric:
[ENVIRONMENT DETAILS]

Annotation color system:
- red arrows = body movement
- blue arrows = camera movement
- green marks = framing / composition notes
- orange marks = lighting direction
- yellow marks = elemental VFX / energy effects
- black text = short lens notes and panel labels

Each panel label also records: camera side, subject screen position, facing/eyeline, movement arrow, and stable end pose for the next panel.

No timestamps. No dialogue. No extra characters unless requested. No logos. No watermark.
```
