# Script Storyboard Board

## Overview

Create a coherent director-style preproduction board for a short film, music video, campaign film, or commercial. Favor a clean 16:9 grid, concise labels, visible scene variety, and cinematic continuity across character, environment, camera movement, lighting, sound, and editorial rhythm.

## Required References

- Read `references/board-spec.md` for every task.
- Read `references/composite-camera-moves.md` whenever the user asks for camera language, complex movement, Dolly Zoom/Zolly, 推拉变焦, 环绕, 跟拍, 钻镜, 转场运镜, or when the shot sequence needs stronger motion variety.

## Workflow

1. Identify the concept: format, brand/story intent, protagonist or product, environment, conflict, emotional arc, runtime, and audience. If the user provides only a rough idea, infer a compact concept instead of asking unless a missing constraint would change the output.
2. Build one shared creative direction: total shot count, unified palette, location logic, weather/time span, texture language, and continuity rules.
3. Design identity anchors: character/model front, back, side, close-up, and relaxed pose references; wardrobe, accessories, silhouette, color accents, and allowed scene-specific changes.
4. Design an outdoor environment with one dramatic natural feature and an overhead route diagram. Mark movement path, camera positions, shot types, subject orientation, and reveal points.
5. Create about 8 numbered storyboard frames unless the user requests another count. Each frame must include shot size, lens/camera feel, movement, action/emotion beat, lighting/mood/style note, and a distinct visual purpose.
6. Add lighting transitions, mood keywords, audio/tone direction, and cinematography notes.
7. Run the scene-diversity pass before finalizing.

## Scene-Diversity Pass

Avoid repetitive scenes. Before delivering, check that adjacent storyboard frames do not repeat the same combination of location zone, shot size, movement type, subject distance, lens feel, and emotional beat.

For an 8-frame board, target:

- At least 4 distinct shot sizes.
- At least 4 distinct camera movement families.
- At least 3 spatial zones or orientation changes within the same location.
- At least 3 lighting/time-quality changes or motivated light shifts.
- Alternation between reveal, approach, contact, distortion, release, and aftermath beats.
- One hero motion beat using Dolly Zoom/Zolly or another composite move when appropriate.

## Output Modes

If the user asks for text only, produce a structured Chinese planning sheet with compact tables.

If the user asks for a visual file, create a 16:9 board as an image, slide, PDF, or HTML page according to the request. Use a professional grid, clear section labels, and concise microcopy. Keep the first screen or final canvas as the usable board, not a marketing landing page.

If the user asks for a generation prompt, output a single prompt that explicitly describes the board layout, section content, visual hierarchy, and cinematic references without overstuffing labels.

## Quality Bar

- Make the board feel like a director's preproduction guide that communicates tone, rhythm, and visual narrative at a glance.
- Preserve identity consistency while allowing minor wardrobe, dirt, wetness, light, prop, or posture variations that are motivated by the scene.
- Prefer precise camera verbs over generic cinematic filler.
- Keep text short enough to fit in panels; reserve dense explanation for notes outside a visual board.
- Include practical production logic: where the subject moves, where the camera sits, why the shot changes, and what the audience should feel.
