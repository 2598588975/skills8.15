# 剧本创作 Skill 整合使用说明

## 推荐入口

优先使用：

`0.剧本总控 · 从灵感到可执行剧本 Skill v1.0.txt`

它负责判断阶段、调用专家、管理版本交接，并最终输出《最终可执行剧本包》。

1. `1.剧本框架 · 项目档案生成 Skill v2.0.txt`
   - 用途：灵感 → 项目档案 / 大纲 / DNA 报告
   - 对应阶段：S1-S3

2. `2.剧本写作 · 大纲扩写与修订 Skill v1.0.txt`
   - 用途：项目档案 + 大纲 → 剧本初稿 / 修订稿 / 台词整合稿
   - 对应阶段：S4 / S6 / S8

3. `3.剧本医生 · 圆桌会诊 Skill v1.0.txt`
   - 用途：剧本 / 大纲 → 多视角会诊报告 + 修改任务清单
   - 对应阶段：S5

4. `4.台词专家 · 全量诊断 Skill v1.0.txt`
   - 用途：结构基本锁定的剧本 → 台词诊断 + 台词替换清单
   - 对应阶段：S7

## 推荐剧本输出格式

短剧、短视频、微电影、AI 视频生成项目，推荐默认使用“中文短剧拍摄稿格式”，而不是英文工业剧本格式。

格式示例：

```text
1-1 青槐路 夜 外
人物：阿远 老周
△暴雨砸在外卖箱上。阿远停在旧墙前，低头看手机导航。
阿远（压着烦躁）：哥，您这地址……是住墙体里吗？
△老周撑着伞站在巷口，手电光从墙面移到阿远脚边。
老周（声音不高，尾音压低）：有人找得到，有人……找不到。
手机提示：预约单已预付。超时将影响评分。
```

核心规则：

1. 场次头使用 `1-1 场景名 日/夜 内/外`。
2. 本场人物单独列出：`人物：角色 A 角色 B`。
3. 动作、画面、调度可用 `△` 开头，但一个 `△` 表示一个连续动作段，不是一句话一个。
4. 对白使用 `角色（状态/发声提示）：台词`。
5. 手机提示、系统音、字幕可以单独写成执行行。
6. 动作发生转折、视角切换、时间跳跃、人物关系变化时，再另起新的 `△`。

## AI 配音标点前置设计

如果剧本后续要进入 AI 配音、AI 视频生成、数字人或 TTS 工作流，台词标点要在剧本阶段就设计好。

标点不是装饰，而是表演提示：

| 标点 | 作用 | 适合情绪 |
|---|---|---|
| 逗号 | 小停顿、组织语言 | 思考、试探、安慰 |
| 句号 | 收住、落地 | 平静、克制、冷淡 |
| 感叹号 | 加重、强调 | 警告、愤怒、兴奋 |
| 问号 | 尾音上扬 | 疑问、怀疑、试探 |
| ？！ | 质问、爆发 | 震惊、愤怒、不敢相信 |
| 省略号 | 情绪卡住 | 难过、紧张、舍不得 |
| 破折号 | 情绪转折 | 迟疑、意识到真相、强调 |
| 波浪号 | 尾音变软 | 撒娇、轻松、亲近 |

推荐写法：

```text
阿远（语速慢下来）：你到底……是谁？
门内女人（OS，声音放轻，尾音稳稳落下）：放门口吧，阿远。
阿远（声音很轻，尾音发虚）：我……吃了。
```

不要只写：

```text
阿远难过地说：我吃了。
```

要写成：

```text
阿远（声音很轻，语速慢下来，尾音发虚）：我……吃了。
```

## 配音友好检查

每次输出正式剧本后，建议检查：

1. 关键情绪台词是否有明确停顿。
2. 不同角色是否有不同气口。
3. 是否存在过度感叹号、省略号、问号。
4. 关键台词是否补了声音大小、语速、呼吸、尾音。
5. 是否有容易被 AI 念成“配音腔”的句子。

建议后续默认保留两版：

1. **中文拍摄稿版**：给导演、演员、分镜、制片看。
2. **配音标点版**：给 AI 配音、数字人、视频生成使用。

## 视频提示词下游接口

如果后续要把剧本转成 Seedance / 可灵 / Runway 等视频提示词，剧本阶段还要额外照顾“镜头生成”的需求。

下游最需要剧本提供：

1. **台词可逐句提取**
   - 对白、OS、VO、手机提示、系统音都要单独成行。
   - 不要把台词揉进动作描述里。

2. **空间调度自然清楚**
   - 每场用动作行写清固定空间关系。
   - 不确定的方位不要乱写，避免下游脑补。

3. **人物方位自然清楚**
   - 谁在门口、谁在墙边、谁在收银台后，要融入场景开头的动作描写。

4. **人物移动关系清楚**
   - 写“从 A 到 B”，不要只写“走过去”。

5. **心理描写可拍**
   - 少写“他崩溃了”，多写“他攥紧贴纸，嘴唇发抖，勺子停在半空”。

6. **关键道具有视觉描述**
   - 材质、颜色、状态、是否破旧、是否有辨识度。

7. **长台词提前拆分**
   - 单句超过 40 字，后续很难塞进 15 秒视频组，建议剧本阶段就拆。

推荐场次写法不是增加字段表，而是在剧本正文里自然写清空间和调度：

```text
1-5 旧楼楼道 夜 内
人物：阿远 门内女人

△旧楼楼道很窄，404 门在走廊尽头，门缝里透出一点暖光。阿远拎着热粥站在门外，外卖箱靠着墙，手机订单页还亮着。
△门内女人始终不露面，声音从门缝后传出来。
△碗盖上贴着一张泛黄的小贴纸，边角卷起，上面是儿童笔迹：阿元的饭。
门内女人（OS，声音放轻）：放门口吧，阿远。
```

复杂场面也优先用自然动作写人物方位和移动关系。只有多人调度、追逐、打斗、群像场面等确实容易混乱时，才在场后加一句“调度备注”，不要把常规场次写成工程表。

每次正式剧本输出后，建议追加：

```text
【视频提示词接口检查】
1. 台词是否可逐句提取：是 / 否
2. 每场空间关系是否已在动作行中自然写清：是 / 否
3. 人物方位和移动关系是否不用下游脑补：是 / 否
4. 抽象心理是否已转为可拍动作：是 / 否
5. 关键道具是否有视觉描述：是 / 否
6. 是否存在超过 40 字的长台词：是 / 否
7. 是否存在旁白 / 心想 / 回忆等需转画面的标注：是 / 否
```
