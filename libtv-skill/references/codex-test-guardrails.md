# Codex + LibTV 测试阶段人工闸门

将以下规则加入项目根目录的 `AGENTS.md`，或在每次任务开头明确引用。

## 强制规则

1. 禁止自动提交完整短剧、完整剧集或批量视频任务。
2. 每次最多提交 1 个生图任务或 1 个生视频任务。
3. 任何 API 调用前，必须先输出以下内容并等待用户回复“确认生成”：
   - 镜头编号与用途
   - 模型/工作流
   - 完整提示词
   - 参考图文件
   - 画幅、时长、分辨率
   - 本次调用数量
4. 未得到“确认生成”，只能分析、拆解、写分镜和写提示词，不能调用 LibTV。
5. 角色设定、场景设定、服装和道具必须先分别确认。
6. 优先复用既有 session；禁止自动调用 `change_project.py`，禁止自动新建多个项目。
7. 先生成低成本预览；只有用户明确选中的结果才能进入高分辨率或延长生成。
8. 每个生成结果完成后立即停止，报告结果文件、异常和下一步建议，等待人工选择。
9. 不允许后台自动改写已批准提示词；若平台会改写，应在结果记录中注明“最终解析提示词不可见/可能被改写”。
10. 不允许自动删除、覆盖原始素材和已选版本。

## 分阶段权限

### 阶段 A：只规划

允许：剧本拆解、角色卡、场景卡、镜头表、提示词草稿。
禁止：任何 API 生成。

### 阶段 B：单镜头生成

允许：经确认后，每次生成一个镜头的低清预览。
禁止：批量、并发、自动重试、自动升级清晰度。

### 阶段 C：人工选片后剪辑

允许：根据人工选中的素材生成 EDL 和预览版。
禁止：未经确认输出最终版、自动发布、自动上传平台。

### 阶段 D：有限自动化

只有当连续多个测试片段稳定后，才允许将“一个场景内的 3—5 个镜头”作为批次；仍保留角色卡确认、分镜确认、首帧确认、成片预览确认四个闸门。
