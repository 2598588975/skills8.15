# Cinema Vertical Poster

## 核心定位

这个 Skill 只负责 **竖版电影项目海报**，默认主海报比例为 **3:4**。

它不是把三张分镜简单拼成一张展示页，也不是生成游戏 key art、AI 壁纸、短剧噱头封面或商业广告图。

目标是把一个电影概念提炼成：

- 一个来自剧情冲突的片名。
- 一个未解释但有钩子的主视觉。
- 一个清晰的图文层级。
- 一个能扩展到横版封面、竖屏封面和社媒主图的视觉体系。

如果用户要 **3 张 21:9 叙事镜头**，不要使用本 Skill，改用 `$cinema-dna-21x9x3`。

## 默认输入

用户可能提供：

- 一句话电影概念。
- 小说、历史、神话、科幻或现实故事。
- 人物关系与情绪方向。
- 已有三联分镜或三张电影画面。
- 海报参考图或版式参考。
- 片名、英文名、slogan 或发布场景。

若信息足够，不要阻塞提问，直接合理补全。只有当题材、主角和海报用途都缺失时，才问一个简短问题。

## 工作顺序

每次先在内部完成判断，再输出海报方向或直接生成图像。

1. 提炼影片核心命题：人物想完成什么，制度/空间/关系阻止什么，最后有什么无法挽回的变化。
2. 判断影片气质：亲密记忆、黑色幽默、制度焦虑、史诗权力、东方历史、科幻技术、青春旅行、体育身体压力、超现实怪诞或温暖生活。
3. 若用户未给片名，生成 5-8 个片名候选，并选择一个主片名。
4. 提取一个主视觉符号，一个人物/群体关系，一个空间压力，一个综合色系统。
5. 设计 3:4 竖版主海报构图，不拼贴三联分镜。
6. 规划文字层级：片名最大，英文名/logline 次之，其他信息极少。
7. 输出底图 prompt 和文字叠加说明；需要完整体系时，补充横版、方图、9:16 封面的扩展规则。

## 命名规则

片名必须来自剧情冲突，而不是来自题材标签。

要求：

- 中文片名优先 2-6 个字，除非题材天然需要更长。
- 可以提供一个英文副名，但不要像机翻片名。
- 片名要暗示不可解决的状态、空间压力或关键动作。
- 避免“AI电影”“赛博史诗”“东方奇幻”“未来之城”这类泛题材名。
- 不使用现成 IP 名、导演名、平台名、真实商业品牌名或可识别真人姓名。

命名输出格式：

```markdown
### 片名候选
1. ...
2. ...

### 推荐片名
- 中文名：
- 英文名：
- 一句话 logline：
- 命名理由：
```

## 海报不是分镜拼贴

主题海报必须重新组织主视觉。它可以借用分镜中的人物、空间、道具、综合色和冲突，但不能把三张 21:9 图直接堆成一张“分镜展示页”。

主海报固定为 **3:4 竖版比例**。海报 prompt 必须明确写入：

```text
3:4 vertical cinematic poster composition
```

不要默认使用 2:3、电影横幅、手机壁纸或社媒方图。

有效海报结构：

- 一个决定性主图：人物、空间或符号只保留一个视觉中心。
- 一个清晰文字层级：片名最大，副标题或 logline 次之，其他信息极少。
- 一个可延展视觉系统：颜色、字体、符号和构图能扩展到预告封面、横版 banner、竖版海报和章节封面。
- 一个未解释的剧情钩子：观众能感觉有故事，但海报不讲完剧情。

无效海报结构：

- 三张分镜缩略图并列。
- 人物大头加背后大场景加到处发光。
- 游戏 key art、短剧土味封面或流媒体算法缩略图。
- 塞入太多宣传语、演员表、日期和小字。

## 参考海报抽象分析

当用户提供海报参考图时，只分析设计手法，不复制具体海报。每次最多抽取一个主维度：

- 排版方法：大留白、小字居中、标题压住人物、字距拉开、纵向标题、边缘信息栏、文字穿插景深、书写笔触覆盖画面。
- 图文关系：文字像空间结构、文字像情绪痕迹、文字遮挡关键局部、文字被人物或道具切开、文字作为画面唯一高饱和符号。
- 色彩方法：单色底加强对比标题、低饱和照片加一枚荧光字色、黑白水墨加金/红点睛、红蓝情绪冲突、暖色生活底加冷色信息层。
- 材质方法：胶片颗粒、印刷网点、旧海报纸感、手写墨迹、粗刷痕、模糊摄影、局部过曝、低清晰度压缩感。
- 版式节奏：中心静止、斜向运动、底部横向运动条、顶部空压、人物贴边、物件居中、小人对巨型环境。

禁止：

- 复用参考图的片名、现成 IP、导演名、演员名、品牌名、奖项标识和发行信息。
- 复用同一人物姿态、同一物件组合、同一文字位置和同一综合色组合。
- 把“红底白字”“大脸叠字”“水墨大字”“人物群像站排”等具体样式当成固定模板。
- 同时借用参考图的构图、配色和字体气质；两项以上接近就必须重写。
- 让海报一眼看出某张具体参考海报的轮廓。

## 根据电影气质选择设计系统

主题海报必须先判断影片气质，再选择设计系统。不要先套“高级海报模板”。

| 电影气质 / 主题 | 排版方式 | 字体与文字形态 | 色彩策略 |
|---|---|---|---|
| 亲密、记忆、逝去关系 | 大留白，人物小比例或贴近底部，标题低声出现 | 细衬线、轻字重、宽字距，少量小字 | 褪色蓝、奶白、旧照片暖灰，一枚柔和点睛色 |
| 欲望、暧昧、室内关系 | 人脸或身体局部被裁切，文字像薄雾覆盖 | 极细无衬线或细衬线，字距拉开，透明度低 | 暗金、酒红、烟褐、局部肤色高光 |
| 犯罪、黑色幽默、失控群像 | 标题大而硬，人物被标题压住或切开 | 粗窄无衬线、压缩字形、粗糙印刷边缘 | 黑、脏白、血红、旧报纸米色 |
| 史诗、战争、权力崩塌 | 一个巨大笔触或符号统治画面，人物缩小为运动带 | 粗刷字、碑刻感、强手写势能 | 黑、深蓝、朱红、金色或冷白闪电 |
| 东方、水墨、历史、山水 | 大面积留白或墨块压境，小人对山水/器物 | 毛笔字但避免装饰化，竖排或边栏小字 | 墨黑、宣纸白、土金、石绿、少量朱红 |
| 青春、旅行、轻叙事 | 文字与自然/道路/天空共处，信息轻盈 | 手写体或明亮无衬线，标题可倾斜但要克制 | 草绿、天蓝、日光黄、低饱和胶片色 |
| 科幻、制度、技术焦虑 | 字体像界面/系统/建筑墙体，人物被网格压住 | 几何无衬线、等宽字、断裂字形、编号感 | 冷蓝、紫灰、荧光橙/绿，低亮度金属底 |
| 体育、速度、身体压力 | 标题参与运动方向，文字被球、汗水、栏杆遮挡 | 粗体无衬线、压缩大字、局部动感模糊 | 场地原色加一枚高亮队服色，允许色散但不过量 |
| 超现实、怪诞、黑色幽默 | 物件符号居中，人物比例不合常理，文字像标签或误植 | 不稳定手写、错位字距、局部反常排版 | 糖果色撞脏色，或单色背景上突兀高饱和物 |
| 温暖家庭、生活叙事 | 画面保留日常空气，标题不压迫人物 | 温和衬线、圆润无衬线、手写小标题 | 暖白、木色、绿、旧胶片黄，降低黑位 |

输出海报 prompt 前，必须写清：

- 为什么选择这种排版方式。
- 文字应该服务哪个剧情钩子，而不是只做装饰。
- 标题与人物、空间或物件之间的遮挡、距离或比例关系。
- 主色、辅色和点睛色分别来自什么场景事实。
- 字体气质是印刷、书写、碑刻、系统界面、旧报纸、展览目录、手工小剧场中的哪一种。

## 文字与排版规则

图像模型不稳定生成准确文字。默认采用两段式工作流：

1. 先生成无文字或只保留极少大字空间的主视觉底图。
2. 再用排版工具、HTML/CSS、Pillow、Photoshop 或设计软件叠加准确片名和小字。

如果用户明确要求图像模型直接生成带文字海报：

- 只放一个短片名，尽量不放小字。
- 在 prompt 中写明 exact title text。
- 给文字留出明确位置，例如 top-left、center vertical、bottom safe area。
- 接受文字可能需要后期校正，不把准确小字作为唯一成败标准。

普通竖版海报任务：

```markdown
### 电影判断
- 核心冲突：
- 影片气质：
- 主视觉符号：
- 空间压力：
- 色彩系统：
- 字体气质：

### 推荐片名
- 中文名：
- 英文名：
- Logline：

### 竖版海报方向
- 主海报比例：3:4
- 构图：
- 图文关系：
- 文字叠加建议：

### 海报底图 Prompt
English prompt...
```

完整视觉体系任务：

```markdown
### 视觉体系封面
- 推荐片名：
- 英文名：
- Logline：
- 主视觉符号：
- 海报核心画面：
- 海报设计策略：
- 色彩系统：
- 字体气质：
- 排版层级：
- 主海报比例：
- 可扩展封面比例：
- 海报底图 prompt：
- 文字叠加说明：
```

比例规则：

- 3:4 竖版主海报，固定比例。
- 16:9 横版视频封面。
- 1:1 社媒封面。
- 9:16 竖屏短剧封面。

如果用户只说“直接生成”，保留分析在内部，直接生成或输出最终 compact prompt。

## 负面约束

避免：

- 三联分镜拼贴页。
- 游戏海报、CG key art、AI 壁纸。
- 廉价短剧封面、流媒体噱头缩略图。
- 人物大头加背后大场景加全屏发光。
- 标题平均摆满，没有主次。
- 太多演员表、日期、奖项、小字和假发行信息。
- 随机 faux text、乱码中文、错误英文。
- 直接复制参考海报。
- 直接复制具体电影、导演、演员或现成 IP。
- 过度油腻 AI 光效、塑料皮肤、HDR、赛博霓虹默认化。

## 最终自检

生成前检查：

- 片名是否来自剧情冲突，而不是题材标签？
- 主视觉是否只有一个明确中心？
- 文字是否有层级，而不是平均摆满？
- 主海报是否固定为 3:4 竖版比例，并在 prompt 中明确说明？
- 海报是否能脱离分镜单独成立？
- 色彩、字体和符号是否能扩展成系列？
- 排版、字体和颜色是否由影片气质决定，而不是套用参考图模板？
- 是否只抽取参考图的一个设计维度，并避开具体片名、人物关系、物件组合和版式轮廓？
- 是否像电影项目封面，而不是游戏海报、AI 壁纸或短剧噱头图？

任一关键检查不通过，必须重写，不进入生成。
