# 双轨长镜头与演技连续性

## 适用场景

用于以下要求：

- AI 演员、演技派、情绪层层失守
- 人物一边完成任务，一边发生强烈内心变化
- 8–15 秒单镜头面部特写或近景
- 惊恐到悲痛、职责与亲情冲突、强忍后哭泣
- 用户提供参考视频并希望复现其表演逻辑

## 一、先锁定外部任务线

写情绪前，先回答：

1. 人物正在持续做什么？
2. 哪个姿势、方向、道具或空间关系必须保持？
3. 什么情况下任务才会被解除？

常见外部任务：

- 举枪瞄准、驾驶车辆、守住入口
- 继续行走、抱住某人、等待命令
- 面向审讯对象、读完信件、完成告别

除非用户或剧情给出解除条件，把任务动作写为全程不变量。情绪应在任务内部发生，不要自动让人物放下道具、转身离开或停止行动。

提示词句式：

```text
外部动作始终保持：他仍维持原来的举枪姿势，双手与枪口方向基本稳定；所有情绪变化主要发生在眼神、眼睑、呼吸、嘴部和下巴，不因悲伤自动放下武器。
```

根据具体任务替换动作，不机械使用“举枪”。

## 二、建立公开层与隐藏层

为人物同时定义：

- **公开层**：人物为了职责、尊严、谎言或保护他人而维持的表情。
- **隐藏层**：正在积聚、试图泄露的真实情绪。
- **残留层**：前一阶段没有消失、仍留在脸上的情绪痕迹。

例：

```text
公开层仍是警觉和职责感；隐藏层是认出战友后的惊恐与否认；当悲痛出现时，警觉、自责和不敢相信仍残留在脸上。
```

避免写成：

```text
惊恐消失，变成伤心；伤心消失，变成哭泣。
```

改写为：

```text
警觉没有完全消失，惊恐从眼神中渗入；随后悲痛覆盖上来，嘴角和下巴开始失守，但目光里仍残留不敢相信和职责压力。
```

## 三、使用波浪式失守

长镜头不要线性增加情绪强度。使用：

```text
维持控制 → 第一处裂缝 → 短暂压回 → 情绪反弹
→ 再次尝试控制 → 最终失守并停留
```

每次“压回”都要有可见依据：

- 嘴唇重新抿住
- 呼吸暂时恢复
- 眼睛短暂闭合后重新睁开
- 下颌重新绷紧
- 视线重新锁定目标
- 表情幅度短暂减小

反弹时只升级一至两个通道：

- 水光变成泪滴
- 无声换气变成破碎呼吸
- 嘴唇轻启变成想说话却发不出声音
- 下巴绷紧变成克制颤抖

不要让眉毛、眼睛、嘴巴、头部、肩膀和双手同时达到最大强度。

## 四、设置关系视线锚点

视线不是装饰，而是人物关系的连接线。

先确定锚点：战友、爱人、孩子、敌人、镜头外声音或关键物品。再判断人物是否能够移开视线。

- **职责或对峙**：多数时间锁定对方；允许短暂失焦、闭眼或侧移，然后重新锁定。
- **羞耻或逃避**：允许较长时间避开，但要写清避开的原因。
- **告别或不舍**：可能反复离开又返回，形成犹豫。
- **震惊认出**：先停住或失焦，再重新确认目标。

不要为了“自然”让所有人物随机看向旁边。视线必须服务于任务和人物关系。

## 五、设计未完成表达

没有台词不等于嘴部完全静止。可以使用：

- 嘴唇像要叫出名字般轻启，最终没有声音
- 吸气准备说话，却在第一个音节前停住
- 嘴唇张开又重新抿紧
- 喉咙吞咽，呼吸从鼻腔变成破碎的口呼吸
- 声音被哭腔堵住，只留下极轻的气声

不要擅自写出用户没有提供的台词。未完成表达只呈现“想说而没有说出”的状态。

## 六、参考式表演示例

剧情：人物保持举枪，认出枪口另一端是战友，逐渐哭泣。

表演逻辑：

1. 外部任务保持：举枪姿势、枪口方向和人物站位不自动改变。
2. 公开层保持警觉，眼眶和嘴唇先泄露不敢相信。
3. 视线短暂侧移或失焦，再回到战友脸上确认。
4. 嘴唇轻启，像要叫出名字，但没有声音。
5. 人物重新抿住嘴唇并控制呼吸，短暂收回表情。
6. 情绪再次反弹，眼泪出现，下巴和嘴角开始克制颤抖。
7. 最终哭意明显，但职责、自责和不敢相信仍同时存在；外部动作是否解除取决于剧情，不由情绪自动决定。

## 七、写作模板

```text
[时长与镜头]。外部任务始终保持：[不可改变的动作、道具、方向和站位]。

[阶段一] 人物公开维持[表层状态]，但[隐藏情绪]已经通过[极弱线索]泄露。

[阶段二] 因为[触发或认出]，[眼神或呼吸]先出现裂缝；[旧情绪]没有消失，[新情绪]开始渗入。人物的视线短暂[闭眼/失焦/侧移]，随后重新回到[关系锚点]。

[阶段三] 人物试图恢复控制：[压回动作]，表情幅度短暂减小；外部任务仍保持不变。

[阶段四] 情绪再次反弹，[泪水/声音/嘴角/下巴]升级；人物出现[未完成表达]，但不增加台词。

[最终阶段] [复合情绪]同时停留在脸上。除非剧情明确要求，人物不自动停止外部任务。
```

## 八、失败检查

- 是否因悲伤自动放下道具或停止任务？
- 是否把情绪写成一张脸替换另一张脸？
- 是否只有持续升级，没有一次压回或恢复控制？
- 是否让视线无原因地随机游移？
- 是否擅自补出人物没说过的台词？
- 是否所有面部和身体通道同时用力，导致夸张表演？
- 是否在流泪后仍保留职责、恐惧、自责或其他残留情绪？
