# 16:9 电影制作板规范

## 目录

1. 画布与网格

## 画布与网格

- 使用 16:9 横版画布；位图推荐 3840×2160，最低 1920×1080。
- 使用 12 列网格，外边距约画布宽度的 3%，列间距约 1%。
- 保持浅底深字或深底浅字的高对比；全板使用 1 套主字体、1 套数字/技术标签字体。
- 让视觉参考图承担氛围，短标签承担定位，完整文字放入伴随镜头表。

推荐纵向分区：

1. 顶部栏约 10%：共享创意指导。
2. 上部约 30%：角色与风格 4 列；环境场景 5 列；俯视动线 3 列。
3. 中下部约 48%：4×2 的八镜头故事板。
4. 底部约 12%：灯光时间线、情绪关键词、音频和摄影笔记。

## 必备区域

### 共享创意指导

在顶部栏写明：

- 项目名、类型、总时长、画幅、版本。
- 镜头数量和节奏结构。
- 统一调色板（3–5 色）。
- 环境背景、天气和时间范围。
- 一句话叙事/广告命题。
- 全局禁止项与身份锁定项。

### 角色与风格参考

同一角色至少呈现：

- 正面、背面、侧面。
- 面部特写。
- 放松或自然姿态。
- 服装、鞋、配饰、标志性道具的局部参考。

写明不可变化项：脸型、五官比例、年龄、体型、发型轮廓、服装结构、主要配饰。写明允许变化项：风吹、湿度、尘土、情绪、局部衣物状态和环境反光。

### 环境与场景设计

至少包含：

- 一张主环境概念图，突出戏剧性自然特征或空间骨架。
- 一张俯视示意图。
- A→B→C 角色/产品路线。
- C1–C8 相机位置、朝向和移动箭头。
- 障碍、入口、出口、目标点、主光源和高低差。

### 故事板

默认八格，编号 01–08，采用 4×2 排列。每格只保留：

- 镜头编号与时间码。
- 景别和镜头感觉。
- 运镜短名。
- 动作/情绪一句话。
- 灯光或声音关键词。

完整操作、连续性和政策说明写入伴随镜头表，不要塞进小格。

### 灯光、情绪和声音

底部以一条从左到右的时间线表现：

- 一天中时间：黎明、上午、正午、黄昏、蓝调时刻、夜晚等。
- 光质：柔和漫射、硬侧光、逆光、顶光、实景灯、体积光。
- 色温和对比度变化。
- 情绪关键词与主题词。
- 环境声、关键拟音、音乐类型、节拍或静默点。
- 镜头和后期哲学：焦段、运动稳定度、颗粒、黑位、高光、锐度、运动模糊。

## 故事板帧规范

每格视觉必须显示：

- 清楚的主体位置和视线方向。
- 前景、中景、背景中的至少两层空间。
- 相机相对主体的高度与方向。
- 运动箭头或轨迹（如有）。
- 与上一格不同的构图主关系。

避免八格都使用人物居中、中景、平视和同一背景。让广角负责空间，近景负责关系，特写负责转折，微距负责证据或产品细节。

## 去同质化规则

为每格记录八维差异：

`区域 / 景别 / 高度角度 / 焦段感 / 运动方向 / 前景 / 光线 / 情绪功能`

- 相邻镜头至少改变 2 项。
- 连续三镜不得重复“平视中景 + 单向前推”。
- 同一地点时，用不同的空间区域、遮挡层、朝向和高度建立新信息。
- 同一动作拆镜时，每个镜头必须回答不同问题：在哪里、谁控制、发生什么、感受如何、结果是什么。

## 视觉生成与排版

采用两阶段流程：

1. 生成角色板、环境图、俯视图和 8 张故事板画面。
2. 使用确定性排版工具组装文字与网格。

不要让图像模型一次生成包含大量中文的完整制作板。若只能一步生成，文字限制为区域标题、镜头号和极短标签，并在交付前复核乱码。

## 交付检查

- 16:9 比例正确。
- 顶部栏、三块参考区、八格故事板和底部技术区齐全。
- 角色板包含五个要求角度/姿态。
- 俯视图路线、机位和故事板编号一致。
- 八格在缩略图中明显不同但综合色统一。
- 所有主标题、数字和镜头编号清晰准确。
