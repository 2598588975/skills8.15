# 减法式微表情提示词

## 核心原则

```text
少即是多，动即是稳。
```

视频表演不要堆叠满格情绪。使用以下三层结构：

```text
强度控制 + 动作归因 + 时间顺序
```

- **强度控制**：限制表情幅度，避免假笑、僵脸和广告摆拍感。
- **动作归因**：让身体、视线和呼吸成为表情产生的原因。
- **时间顺序**：写出情绪从何处开始、如何变化、在哪里结束。

## 一、控制情绪强度

避免只写“开心地笑”“非常悲伤”“害羞地看镜头”。这类结论容易使模型把情绪固定在最大值。

将抽象情绪改写为：

```text
[人物状态] + [低强度情绪] + [嘴角或眉间微动] + [眼神状态]
+ [面部肌肉与呼吸状态] + [非摆拍要求]
```

中文例句：

```text
她神态放松，嘴角只带着一丝很淡的笑意，目光柔和，面部肌肉自然松弛，呼吸平稳，像被镜头偶然捕捉到，而不是主动摆出笑容。
```

英文模型需要时可使用：

```text
The character has a faint, subtle or barely visible emotion; facial muscles remain relaxed, breathing naturally, realistic and candid, not posing.
```

程度词：

- 微弱的 / faint
- 轻微的、微妙的 / subtle
- 几乎看不见的 / barely visible
- 被压住的、克制的 / suppressed
- 放松的 / relaxed
- 自然呼吸 / breathing naturally
- 抓拍感、非摆拍 / candid, not posing

不要机械地在每段提示词中加入所有词语。根据情绪强度选择一至两个即可。

## 二、给表情一个动作原因

真实表情通常是对人、事件或身体动作的反应，而不是孤立的面具。

```text
身体微动 + 视线转移 = 可读的微表情
```

改写顺序：

```text
人物感到[情绪]或受到[触发]。
人物先做出[身体微动作]，以[动作目的]。
视线[移动方式]，同时出现[嘴部、头部或手部动作]。
作为结果，[低强度微表情]自然浮现。
```

例：不要只写“她很害羞”。改为：

```text
听见对方的话后，她立刻垂下视线，轻轻收住下巴，避开对方的注视；目光向旁边短暂游移，嘴唇轻轻抿住，随后嘴角才浮现出一个几乎看不见的紧张笑意。
```

可选动作：

- 低头、收下巴、缓慢闭眼、重新抬眼
- 视线移开、向下看、短暂侧瞥、重新聚焦
- 深吸气、短暂停住呼吸、缓慢呼气
- 肩膀放松或轻微下沉
- 嘴唇抿紧、轻启、下巴轻微绷紧
- 与剧情有关时才使用挽头发、咬下唇、挠后脑勺、揉眼睛或低头看手机

不要同时加入过多动作。动作必须与人物性格、场景和情绪有因果关系。

## 三、写出时间顺序

微表情的本质是变化。至少使用：

```text
Start 起始状态 → Transition 触发与变化 → End 最终微表情
```

通用公式：

```text
视频开始时，人物处于[起始状态]，面部肌肉[松弛或克制]。
随后，因为[触发原因]，人物做出[身体微动作]，眼神[视线变化]，嘴部[细微变化]。
最后，一个[低强度程度词]的[最终情绪]慢慢浮现在脸上。
整体动作克制、真实、自然，有呼吸和轻微回落，不像摆拍。
```

适合用作起始状态：

- 平静、中性、发呆、疲惫
- 严肃、坚忍、警觉
- 心不在焉、无聊、压抑

适合用作触发动作：

- 眉毛轻轻抬起或眉间开始收紧
- 视线突然停住、移开或重新聚焦
- 缓慢闭眼、深吸气、屏住呼吸
- 肩膀轻轻下沉、头部缓慢低下
- 嘴角停顿、嘴唇抿紧或轻启

适合用作最终状态：

- 温暖或释然的淡笑
- 震惊后留下的警觉
- 一滴自然落下的眼泪
- 困惑的轻蹙眉
- 微弱担忧、失望或悲伤

## 四、对照改写

### 开心

弱写法：

```text
女人喝着咖啡，开心地笑着，享受这个早晨。
```

减法写法：

```text
她轻轻举起杯子闻到咖啡香气，双眼自然闭合一瞬，随后缓慢吹散杯口的热气，暂时没有喝下。她的面部肌肉逐渐放松，嘴角浮现很淡的舒适笑意，呼吸平稳，没有看向镜头摆姿势。
```

因果链：

```text
闻到香气 → 闭眼感受 → 吹散热气 → 身体放松 → 舒适笑意出现
```

### 害羞

弱写法：

```text
她害羞地一直看着镜头，对观众微笑。
```

减法写法：

```text
她听见对方的话后立刻垂下视线，轻轻收住下巴，不敢继续与对方对视；目光紧张地向旁边瞥了一下，嘴唇轻轻抿住，随后才出现一个克制而短暂的害羞笑意。
```

因果链：

```text
受到触发 → 低头 → 避开对视 → 侧瞥 → 紧张笑意出现
```

### 释然

弱写法：

```text
男人露出释然的笑容。
```

减法写法：

```text
开始时，他神情严肃而克制，望着远处。随后，他缓慢闭上双眼，完成一次清晰而平稳的深呼吸，肩膀随呼气轻轻下沉。当他重新睁开眼睛时，目光已经柔和下来，嘴角才慢慢浮现一个很淡的释然笑容。
```

因果链：

```text
严肃克制 → 闭眼 → 深呼吸 → 肩膀放松 → 重新睁眼 → 释然微笑
```

## 五、使用边界

- 不要把“微表情”误解为始终低强度。用户明确要求爆发、崩溃或大笑时，可以提高强度，但仍需保留发生过程和自然回落。
- 不要为了真实感强行加入与剧情无关的手部动作。
- 不要把人物限制成完全静止；细小眨眼、换气、视线和肌肉回落有助于避免表情冻结。
- 不要要求害羞人物始终直视镜头，或要求恐惧人物保持完全放松等互相冲突的动作。
- 不要把负向词堆满结尾。正向描述清楚动作逻辑后，只保留最必要的限制。

## 六、写完后的九项检查

1. 是否只写了开心、悲伤、害羞、愤怒等情绪结论？
2. 是否使用恰当的低强度程度，而非默认满格？
3. 表情是否在整段视频中存在呼吸、变化和回落？
4. 是否写出起始状态、变化动作和最终结果？
5. 表情是否有清楚的发生原因？
6. 是否由身体、视线或呼吸带出表情，而不是直接摆表情？
7. 视线是否符合情绪逻辑，而不是始终盯着镜头？
8. 物理动作是否少而准确，并与剧情相关？
9. 是否避免夸张表演、强迫式笑容、僵硬脸和摆拍感？

一句话检查：

```text
不要只写人物有什么情绪；写清为什么产生、身体先怎么动、眼神如何变化、情绪怎样慢慢出现。
```
