# 默认参考质感基线

当用户要求“诺兰感”“大银幕实拍感”但没有提供新的视觉参考时，先使用本基线。它来自一组跨城市、郊区、海岸、树林和室内画面的共同规律，不复制任何具体电影 LUT，也不得复刻人物、地点、服装或完整镜头；默认色彩统一遵守 [color-signature.md](color-signature.md) 的 house color。

## 使用优先级

1. 用户明确指定的主体、场景、时代、动作、天气、光源和画幅优先。
2. 用户提供新参考图时，以新参考图的跨图稳定证据覆盖本文件中的色彩和构图倾向。
3. 新参考图不能覆盖写实、克制、物理可信和反概念图规则，除非用户明确要求其他类型。
4. 没有新参考图时，把本基线作为默认视觉重心，不必逐条写进提示词。

## 目标视觉签名

### 1. 普通世界先于戏剧装置

- 优先选择真实街道、住宅边缘、旧院落、树林、海岸、山路、普通店铺与功能建筑。
- 场景可以陈旧、荒凉或潮湿，但不要把每个表面都做成同等破败的布景。
- 允许人物只是行走、站定、等待或看向画外；安静画面不必靠信封、钥匙、倒计时或警报证明它“有故事”。
- 人物像被摄影机撞见，而不是为海报摆姿势。背影、侧面、动作中途和短暂停顿都可以成为完整画面。

### 2. 横向空间与稀疏构图

- 默认使用真实横向 16:9 或 2.39:1 画布。不要把上下黑色 letterbox 烧进画面；只有用户明确要求黑边时才添加。
- 广景和中远景优先展示道路、地平线、林线、水面、建筑边缘或人流方向。中景与近景只在人物或动物确实是信息核心时使用。
- 允许人物位于中央，但居中必须由道路、树冠、地平线、建筑通道或人流组织，不能变成人物海报。
- 保留大片安静表面：天空、路面、水面、树林暗部、墙体或普通玻璃。不要让每一区域都承担叙事信息。
- 焦段优先采用自然透视范围：约 35–65mm；只有交代辽阔地理时才更广，只有隔着人流或玻璃观察时才更长。
- 机位通常接近人眼、肩部或腰部高度；低机位必须由道路坡度、主体高度或动作需要支持。

### 3. 单一环境主光

- 优先使用阴天、清晨、傍晚、窗外天光或现场已有灯具形成的自然光比。
- 让天空、窗面或远处地平线略亮，让人物和环境中间调偏暗；暗部保留空气、轮廓和材质，不压成纯黑。
- 高光柔和滚降，可呈灰白、暖灰白或旧象牙色；不要出现 HDR 白边或商业棚拍式均匀补光。
- 夜景以一种现场光为主，其他灯只作为小面积现实点光。不要同时把绿色荧光灯、橙色路灯、霓虹招牌和湿地反光都强化。

### 4. 默认硬色彩签名

- 所有材料通过同一青绿—暖灰胶片色彩管线：阴影为深青绿或蓝绿黑，中间调持续偏青灰绿，高光为脏暖灰、灰黄或旧象牙色。
- 青绿色必须贯穿道路、墙体、衣物、毛发、植被与空气透视，不能只存在于植物局部；灰色材料应成为绿灰或青灰，而不是中性水泥灰。
- 使用选择性饱和：压低鲜红、鲜黄、纯蓝和无关杂色，同时保留青绿阴影与青灰绿中间调的色彩密度。不得用“低饱和”把画面洗成黑白。
- 一个小面积现实强调色即可，例如旧橙外套、褐色土路、暗红项圈或远处暖灯；强调色不能扩散为典型青橙大片配方。
- 肤色、毛发、布料、沙土和建筑材料保留相对差异，但都接受同一环境偏色，不能成为脱离画面的中性色贴图。

### 5. 实拍镜头响应

- 中等解析感，有限景深，主体清楚但不锐利到数字化；远景与边缘自然变软。
- 使用细而可见的胶片颗粒、轻微镜头柔度、适度微对比和自然空气透视。
- 点状灯光可有很轻的晕染，高光过渡应柔和；不要大面积梦幻辉光、重度柔焦或镜头污渍特效。
- 禁止 8K 锐化、HDR、全景深、每根草和每处锈迹都同等清楚的概念图质感。

## 静态图片预算

一张图片默认只保留：

- 一个主体或一组不可拆分的主体关系。
- 一个主空间关系。
- 一个主光线逻辑。
- 零到一个叙事线索。

默认不新增解释性道具、可读长文字、装饰性天气或警示装置。用户原始设定已经足够形成画面时，宁可停在空间、动作和光线，不继续发明故事。

## 组合风险门禁

下列元素若不是用户硬性要求，同时出现三项或以上时，必须删减到最多两项：

- 装饰性雨夜或大面积湿地镜面反光。
- 强绿色荧光灯。
- 大面积橙色路灯、暖黄反光或青橙对撞。
- 大块可读文字、长中文招牌或多处标牌。
- 红色倒计时、警报、仪表红区或发光数字。
- 信封、文件、钥匙、照片等解释性道具。
- 每个表面同等脏旧、潮湿、锈蚀或开裂。
- 玻璃水滴、烟雾、灯晕、反射等多重前景效果。

若其中某项是用户硬性要求，保留该项并减少其他装置、色彩强度和材质数量。不要通过新增另一种戏剧元素来“平衡”画面。

## 夜景与雨景

- 用户明确要求夜晚或下雨时，保持真实夜景或雨景，不擅自改成白天。
- 先确定一个主光源：店内顶灯、路灯、车灯或窗光四选一；其他灯仅作小面积环境证据。
- 湿地只在确实下雨且路面可见时出现，反光保持断裂、低亮度和局部性。
- 玻璃雨滴、招牌、倒计时、道具和烟雾不能同时承担叙事。人物等待、行走或观察本身可以成立。

## 动作与明亮场景适配

- 高速行动、历史战争、沙漠、雪地、火光或明亮日景不强制使用阴天、欠曝光或静止构图，但仍继承深青绿阴影、青灰绿环境中间调和脏暖灰高光的相对关系。
- 场景本身决定曝光、天气、运动和局部材料色；统一色彩签名负责让不同题材属于同一视觉世界。

## 输出前自检

- 是否为了“电影感”擅自增加了夜雨、信封、钥匙、倒计时、警报或长招牌？若是，删除。
- 青绿色是否只存在于植物，而道路、墙体、衣物、毛发和空气仍是中性灰？若是，让所有材料通过同一色彩管线，同时保留它们的相对差异。
- 是否只写了“低饱和”，导致画面接近黑白？若是，恢复青绿家族的选择性色彩密度。
- 是否把上下黑边当作画面内容？若是，改为真实横向画布。
- 是否所有表面都同等脏旧、潮湿和锐利？若是，恢复大块安静表面与自然景深衰减。
- 没有额外叙事线索时，主体、空间、光线和动作是否已经成立？若成立，停止添加。
