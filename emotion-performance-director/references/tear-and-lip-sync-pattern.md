# 哭戏与台词口型专项模式

用于单人近景或特写中的蓄泪、破防、哭腔台词、泪水轨迹与口型同步。只在用户明确要求哭戏、流泪、哭着说台词或需要精确剪辑节拍时读取。

## 核心原则

- 把哭戏设计成情绪变化，不把“流泪”当作固定表情贴图。
- 先确定外部触发、人物目标和克制方式，再安排泪水、呼吸、视线和口型。
- 用户原文台词逐字保留；时长不足时先减少无语言动作或拆段，不擅自删词。
- 只有说话者产生口型；台词前后的抽噎、换气和停顿必须符合语义。
- 参考图只锁定被明确认可的身份、发型、服装和气质，不把瞬时表情、背景或光线自动固化。
- 默认使用语义节拍；只有分镜表或剪辑计划才给精确秒数。

## 三阶段哭戏弧线

根据角色和情境调整强度，不固定性别、年龄、服装、镜头或色调。

1. **蓄积与克制**：人物保持原任务，呼吸变浅或短暂停顿，眼周湿润，嘴部与下颌出现轻微控制，泪水尚未明显坠落。
2. **防线出现裂缝**：一个可见或可听触发使控制短暂失败；视线偏移或闭眼，第一滴泪落下，鼻翼、吞咽、下颌或肩颈出现一次有因果的反应。
3. **情绪落点**：人物可能重新压回、低声抽泣、带泪说完台词或彻底失守；必须停在明确的视线、呼吸和身体状态上。

不要让每个面部区域同时满幅运动。每阶段只选择二至四个最有辨识度的线索，保留自然不对称和短暂停顿。

## 台词同步

为台词建立最小表演映射：

```text
原句与说话者 → 说话意图 → 呼吸入口 → 视线目标 → 语速/重音 →
自然停顿 → 口型与面部反应 → 说完后的稳定落点
```

- 哭腔不等于每个字都颤抖；只在情绪压力最大或换气受阻处出现断裂。
- 抽噎不能遮掉关键信息；需要可辨识台词时降低哭声强度或把台词放在一次回稳之后。
- 台词完成后保留一次有意义的余韵，例如重新看向对方、呼气、泪水落下或把情绪压回。
- 无台词时可以设计“想说但没有说出”的嘴唇轻启和呼吸受阻，但不得补写人物没有说的话。

## 镜头与光线

- 特写优先稳定机位或单次有起止点的缓慢推进；不让镜头运动抢走表演。
- 焦段与景深服从人物比例和动作可见性，不把某个机型、100mm 微距或超浅景深设为固定模板。
- 光线保持来自可解释的现场光源，泪痕高光与眼神光必须对应真实方向。
- 不为了“悲伤”自动改变色温；光色只有在场景或可见事件支持时变化。

## 稳定性与负面约束

按镜头风险选择少量约束：人物身份稳定、单人入镜、无多余口型、无面部扭曲、无夸张假哭、无字幕水印、无无因镜头漂移。不要机械粘贴固定负面词库。

## 验收

- 情绪是否有触发、克制、裂缝和落点？
- 泪水、呼吸、视线、口型和身体动作是否属于同一因果链？
- 台词是否完整、说话者正确、可辨识且时长可读？
- 表演是否保留自然强度曲线，而非从头到尾同一幅度？
- 身份、服装、场景、构图和光源方向是否稳定？

本模块吸收并修正了旧 `emotion-dialogue-video-skill` 的三阶段哭戏与口型节拍，移除了固定少女设定、固定镜头器材、固定色温和过度精确的肌肉指令。
