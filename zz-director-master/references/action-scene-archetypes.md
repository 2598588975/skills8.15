# 动作与场景档位

用于动作、追逐、揭示、压迫性文戏或需要明确空间变化的镜头组。先读取 `previs-ai-production.md` 的轴线、调度和连续性规则，再选择一个主档位；不要把多个档位平均混合。

## 目录

1. 九种主档位
2. 动作镜头硬约束
3. 剪辑对比
4. Seedance 执行注意

## 1. 九种主档位

| 档位 | 核心节奏 | 空间设计 | 适用场景 |
|---|---|---|---|
| Impact | 蓄势慢 → 接触快 → 余波可读 | 接触点和受力方向清楚 | 单次撞击、爆发、坠落、破坏 |
| Duel | 试探 → 攻防交换 → 优势转移 | 双方位置、距离和轴线持续可读 | 双人打斗、武器对决 |
| Pursuit | 距离拉近/拉开 → 障碍改变 → 去向明确 | 路径宽窄、出口和相对速度变化 | 追车、奔跑、逃亡 |
| Journey | 出发 → 穿越空间 → 到达或发现 | 路线和地标依次出现 | 行走、航拍、旅程 |
| Atmosphere | 稳定观察 → 微小异常 → 状态落点 | 几乎不换位，让细节承担变化 | 情绪停顿、恐怖铺垫、环境段 |
| Reveal | 遮挡/未知 → 逐步显露 → 关系重估 | 摄影机控制观众何时看见 | 开门、绕角、散雾、身份揭示 |
| Confrontation | 立场建立 → 压力交换 → 权力变化 | 两人轴线、屏幕左右和距离变化 | 摊牌、争执、威胁 |
| Interrogation | 提问施压 → 沉默/回避 → 信息裂口 | 不对等位置、出口和观察关系 | 审问、盘问、逼供 |
| Negotiation | 条件提出 → 试探反应 → 交换或破裂 | 双方保持可比较构图 | 谈判、交易、合作冲突 |

权力变化不等于自动越轴。只有通过中性机位、沿轴镜头、人物换位或可见摄影机移动建立新空间后，才改变轴线侧。

## 2. 动作镜头硬约束

- 写动作意图、路线、接触和结果，不堆叠精确关节角度。
- 破坏过程写清力量方向、接触点和环境反馈，不要求模型同时完成多级连锁破坏。
- 同一连续镜头避免“完全离场后无依据重新入场”。
- 所有关键状态变化必须在画内发生，或用后镜清楚展示其原因与结果。
- 追踪角色通常不超过三人；每次切镜重新确认人物位置、朝向和屏幕方向。
- 镜面、水面和玻璃属于高风险几何，不是绝对禁用；只有叙事必要且反射关系可控时使用。
- 微表情用可见生理反应表达，不只写“愤怒、害怕、悲伤”。
- 每个打击、阻挡、闪避和反击形成“意图 → 动作 → 接触/避开 → 可见反馈 → 回稳或下一招”的因果链。

## 3. 剪辑对比

相邻镜头至少在两个有效维度上形成清楚差异，优先选择：

- 景别：全景/中景/近景发生有意义的信息距离变化；
- 机位：高度、观察方向或主客观关系改变；
- 稳定性：固定、跟随、手持、升降等服务不同节拍；
- 速度：等待、爆发、余波形成节奏差；
- 主体：行动者、受力者、反应者或证据细节切换。

差异不能破坏轴线和连续性。插入镜头必须有因果来源，明确属于谁的手、武器、伤口或道具，不生成无主身体部位。

## 4. Seedance 执行注意

- 单段优先一个决定性动作；复杂动作拆成多个可验收片段。
- 镜头提示词使用现在时、主动语态和清楚结束状态。
- 每次切镜后重申当前人物位置、朝向、道具和动作进度，但不重复已完成动作。
- 不把故事板格线、编号和说明文字当作画面内容。
- 避免“镜头扫过故事板/漫画页”；参考板只提供视觉和调度依据，成片描述真实场景中的动作。
- 失败时先减少角色、动作、摄影机或环境变化中的一个维度，再重试。

本模块吸收了旧 `drama-director` 中仍有价值的场景档位，并按当前轴线、连续性和减法重试规则修正。
