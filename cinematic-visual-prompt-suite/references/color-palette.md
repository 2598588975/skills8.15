# 色卡：

1. 核心色卡提取

请提取图片中的 6–10 个核心颜色，每个颜色必须包含：

中文颜色名

HEX 色值

RGB 数值

画面中的作用（例如：背景 / 阴影 / 服装 / 高光 / 氛围）

使用比例建议（大致百分比）

要求：

颜色要覆盖画面主要视觉构成

不能重复相近颜色

要区分“主色 / 辅色 / 点缀色 / 光影色”

1. 色彩层级

请把提取的颜色归类为以下几类：

主背景色（大面积环境用色）

人物肤色 / 肌理色（皮肤、真实质感）

服装主色（衣服主体颜色）

阴影色（暗部、压暗区域）

高光色（光源、反光、轮廓光）

点缀色（少量细节，如发饰、武器、叶子等）

环境氛围色（空气感、雾气、空间色）

要求：直接给我生成色卡图片

每一类最多列 1–3 个颜色

必须说明“为什么属于这一类”

分类要符合真实摄影逻辑，而不是随意归类
