# 情绪转折与时间轴

## Seedance 时间控制边界

Seedance 生成提示词默认使用事件顺序和语义节拍，不输出“0–1.5 秒”“2.5–4.5 秒”等阶段时间码。精确时间只作为内部规划或用户明确要求的分镜、剪辑表使用，不能表述为模型必然逐秒执行的硬控制。

用户指定总时长时，在提示词开头提及一次，并让用户在生成设置中选择对应总时长。正文使用：

```text
开场 → 随后 → 中段 → 短暂压回 → 后半段 → 结尾
```

根据镜头复杂度删减节拍；每个节拍只承担一个主要情绪变化。

## 选择原则

先确定转折为何发生，再决定表情如何变化。优先使用事件或台词作为触发点；没有触发点时，可以使用回忆涌现、看见某物或一次呼吸停顿，但不要凭空添加改变剧情的事件。

## 约五秒语义节拍

### 单一表情

- 开场：从中性状态自然建立表情
- 随后：维持表情并加入呼吸、眨眼、视线或轻微回落
- 结尾：自然停留或轻微收束

### 渐变 A → B

- 开场：明确 A
- 随后：触发与桥接，A 逐渐减弱，B 开始泄露
- 结尾：B 完成并停留

### 转折 A → 抵抗 → B

- 开场：建立 A
- 随后：触发点出现，人物短暂停顿
- 中段：人物试图维持 A，但眼神、呼吸或嘴角泄露 B
- 结尾：B 完成，保留一点 A 的痕迹形成复合情绪

## 六至十秒内部节奏规划

构思时可按以下大致比例分配，但 Seedance 成品提示词要把比例转换成语义节拍，不输出百分比：

- 初始状态：20%–30%
- 触发与抵抗：20%–25%
- 桥接与情绪泄露：25%–35%
- 最终状态与余韵：20%–30%

台词横跨多个阶段时，把关键词或停顿放在触发点。不要让人物先完成情绪变化，再机械地说出台词。

## 八至十五秒双轨长镜头内部规划

先写明外部任务或持续动作保持不变，再在内部按波浪分配。最终给 Seedance 的提示词应改写为“开场、随后、中段、短暂压回、后半段、结尾”，不输出百分比：

- 0%–20%：维持外部任务与公开表情，隐藏情绪只留下极弱线索
- 20%–40%：触发或认出，眼神、呼吸或嘴部出现第一道裂缝
- 40%–55%：人物短暂压回情绪，重新控制表情和呼吸
- 55%–75%：情绪反弹，旧情绪与新情绪同时存在，眼眶、声音或下巴开始失控
- 75%–90%：再次试图维持任务，但控制失败，泪水或哭腔出现
- 90%–100%：最终情绪停留；除非剧情要求，外部任务仍不自动解除

不要把每个阶段都写得比前一阶段更大。短暂回收、停顿和重新控制是长镜头表演的重要节奏。

## 常见转折

### 笑着笑着哭了

1. 真实笑意建立在眼睛、脸颊和嘴角。
2. 笑声或台词在触发词后逐渐减弱。
3. 嘴角继续维持笑意，视线却停顿或失焦。
4. 呼吸卡住，眼眶湿润，嘴角出现细微颤动。
5. 一滴眼泪落下，笑意没有完全消失。

### 哭着突然笑了

1. 先建立泪水、哽咽或失控后的余波。
2. 触发点让人物愣住，视线重新聚焦。
3. 嘴角先出现不确定的小幅上扬。
4. 笑意扩展但泪痕仍在，形成释然或荒诞感。

### 愤怒转为失望

1. 眉间、下颌和注视建立克制愤怒。
2. 听见或看见触发内容后停顿。
3. 视线先失去攻击性，下颌和眉间逐渐松开。
4. 目光移开、嘴角下沉、长呼气，落入疲惫与疏离。

### 强装镇定后失守

1. 表情平静，语速和姿态刻意稳定。
2. 通过吞咽、眨眼或一次浅吸气泄露压力。
3. 关键字处声音卡住，视线避开，嘴唇或下巴轻颤。
4. 眼泪积聚或呼吸断裂，最后才允许情绪释放。

### 害怕转为坚定

1. 视线游移、浅呼吸和身体轻微僵硬建立恐惧。
2. 人物停顿并完成一次较深吸气。
3. 视线重新锁定目标，下颌轻收，动作幅度减少。
4. 呼吸稳定，眼神明确，恐惧仍有余痕但不再支配人物。

## 台词绑定示例

台词：“我就知道你一定会回来。”

- “我就知道”：笑意自然，语气带着确认后的欣喜。
- “你一定会”：眼神持续落在对方身上，声音开始放慢。
- “回来”：作为转折词，尾音变轻，笑声停住，呼吸卡顿。
- 台词后：嘴角仍上扬，眼眶逐渐湿润，一滴眼泪落下。

## 防失败调整

- **突然变脸**：延长触发与桥接阶段，减少最终情绪强度。
- **表情冻结**：加入一次自然眨眼、换气、视线变化或笑容回落。
- **表演夸张**：把强度降至 3–5，删除大幅肢体动作和“崩溃、嚎啕”等词。
- **只哭不笑**：明确嘴角在泪水出现后仍保留微弱笑意。
- **只有笑没有泪**：写出眼眶积聚水光到泪滴滑落的因果过程。
- **口型与情绪脱节**：把变化绑定到具体关键词、停顿和台词结束后的余韵。
- **人物崩脸**：采用稳定近景、单镜头、小幅动作，并限制五官、身份和发型变化。
- **情绪一来就停止任务**：锁定外部任务为不变量，只允许必要的肌肉、呼吸和视线变化。
- **情绪直线上升显得机械**：在中段加入一次短暂恢复控制，再让情绪以更高强度反弹。
- **人物无故移开视线**：明确关系视线锚点，只允许短暂闭眼、失焦或侧移，并让视线重新回到目标。
