# Script to Cinematic Production Board

把剧本转译为可执行、可检查、视觉上不重复的导演预制作包。先建立叙事与视觉逻辑，再设计镜头；不要从“炫技运镜清单”反推故事。

## 默认交付

除非用户缩小范围，交付以下内容：

1. 一句话概念与共享创意指导。
2. 角色/服装/配饰与身份一致性规范。
3. 环境设计、俯视动线和机位图。
4. 约 8 个镜头的编号故事板与完整镜头表。
5. 灯光、情绪、声音和摄影处理说明。
6. 每镜可执行的 Seedance 2.0 提示词。
7. 一张 16:9 电影制作板；若当前工具不适合准确排版，先交付完整内容稿和可渲染版式规范，明确未生成视觉成品。

默认镜头数为 8。根据时长和叙事密度可调整为 6–12，但必须在顶部栏写明镜头数、总时长、画幅和版本。

## 读取参考资料

按任务需要读取，不要一次加载全部大型资料：

- 开始任何制作板任务：读取 `references/production-board-spec.md`。
- 选择 Dolly Zoom、环绕、穿行、跟随、旋转或转场复合运镜：读取 `references/compound-camera-movements.md`。
- 编写 Seedance 多模态提示词、素材映射或时间轴：读取 `references/seedance-operating-notes.md`。
- 进行平台安全检查：读取 `references/runway-content-policy.md`。把它作为本地政策快照和安全改写参考，不把“规避”理解为绕过审核。
- 需要案例措辞时，在 `references/seedance-prompt-examples.md` 中检索最相关的 1–3 个案例。优先使用 `rg -n "电影级|商业广告|角色一致性|一镜到底|FPV|环境变换|卡点|微距|转场" references/seedance-prompt-examples.md`，不要通读或照抄整库。
- 需要核对即梦参数、上传限制或原始案例时，读取 `references/seedance-2-manual.pdf` 的相关页。先参考 `references/source-index.md` 定位页码。

## 工作流

### 1. 解析输入

提取并记录：

- 项目类型、总时长、画幅、平台和交付格式。
- 核心命题、观众、产品或叙事目标。
- 角色、地点、道具、动作、对白、情绪转折。
- 用户已经锁定的参考图、视频、音频和品牌要求。
- 不可改变项与允许场景化变化项。

信息足够时直接执行。仅当缺失信息会改变故事主线、品牌事实或角色身份时才询问。

### 2. 先做政策与权利检查

读取政策参考并检查未成年人、血腥暴力、性化、仇恨、自残、真人肖像、隐私、品牌/IP 和在世艺术家风格等风险。对可保留的创意进行安全重构，例如用环境破坏、装备脱手、火花、尘土或非人物体冲击表达强度。

不要使用同义词、拆词或暗语绕过平台政策。若核心请求本身不可执行，明确指出并提供合规的叙事替代。

### 3. 建立剧情节拍

先写 6–10 个节拍，再映射到镜头。默认八镜角色功能：

1. 建立世界与空间规则。
2. 锁定人物/产品与目标。
3. 引发行动或异常。
4. 推进并扩大空间关系。
5. 发现、揭示或情绪转折。
6. 压力升级或关键对峙。
7. 高潮、价值证明或产品英雄时刻。
8. 结果、余韵、品牌落点或行动号召。

不要为了凑八格拆分没有新信息的动作。

### 4. 锁定共享视觉 DNA

定义统一的：

- 色彩主轴与点色。
- 真实度、材质和成像介质。
- 镜头组、景深和畸变倾向。
- 环境天气、时间范围和自然特征。
- 角色面部、比例、发型、服装基线与关键配饰。
- 后期颗粒、对比度、黑位、高光和运动模糊。

将“身份不变”和“场景允许变化”分开写。允许湿发、风吹、灰尘、局部服装状态和情绪变化，但不得改变脸型、年龄、体型比例、标志性服装结构和主配饰。

#### 4.1 统一规则卡

当用户提供全局风格段落、`{{Mixed 1}}` / `{{Mixed 2}}` 等角色参考，或要求角色全片一致时，在镜头表前先输出一张短版统一规则卡。不要长篇堆形容词，不要使用大量负面提示词；优先用正向约束写清要保留什么。

统一规则卡固定包含：

- 角色锁定：脸部、发型、服装、体型比例、身高差、人物气质和参考身份全程一致，角色不得互换；动作、走位、转身、抬袖、抓衣领和互动要符合真实人体运动，加入自然眨眼、呼吸和视线调整。
- 画面风格：项目类型、真实度、成像介质和题材气质。例如“高质感东方玄幻古装女频短剧，真人实景拍摄，超写实电影机质感”。
- 色彩：主色、点色和整体倾向。例如“翠绿色调适当上调，月白、灰绿、低亮暗红形成冷暖层次”。
- 质感：皮肤、发丝、布料、饰品、烟雾和后期质感。例如“轻度黑柔、高光晕散，保留毛孔、唇纹、银饰、袖纱和布料纤维”。
- 镜头：景别、焦段、景深和运动基线。例如“中景到特写为主，女主近景用 100–135mm 长焦，T2.0–T2.8 浅景深压缩空间”。
- 光线：主光、补光、轮廓光和角色冷暖关系。例如“侧后方月白逆硬光，高位顶侧白硬光，正面低亮柔补；男主以手电冷白光和环境反光为主”。
- 背景：空间、烟雾、体积光和远处光效。例如“古洞轻薄烟雾、月白光晕，远处石门和岩缝藏低亮暗红与翠绿，不抢人物面部”。
- 声音：若用户指定无 BGM，明确只保留对白、脚步、呼吸、衣料摩擦、环境声和指定声效；不加字幕。

### 5. 执行镜头去同质化

为每个镜头建立差异向量：

`空间区域 / 景别 / 机位高度与角度 / 镜头焦段感 / 运动方向 / 前景层 / 光线阶段 / 情绪功能`

相邻镜头至少改变其中 2 项；连续 3 镜不得重复同一景别、同一机位高度和同一运动方向。除有意制造仪式性重复外，不得只更换人物动作而保持相同背景、构图和光线。

完成镜头表后增加一行“差异说明”，明确每镜相对前镜的新信息。发现相似时，优先更换空间区域、前景遮挡、机位高度或叙事功能，不要只换焦段名称。

### 6. 设计环境和空间动线

选择一个具有戏剧性自然特征或鲜明空间骨架的主场景。绘制或描述俯视图：

- 标记入口、目标点、障碍、制高点、光源、危险区和出口。
- 用 A→B→C 标记角色或产品移动路径。
- 用 C1–C8 标记相机位置，并标出镜头朝向和移动箭头。
- 在路线旁标注镜头编号、景别和运动类型。

空间动线必须与故事板编号一致。

### 7. 选择复合运镜

先说明镜头的叙事目的，再从复合运镜库选择。八镜方案默认只使用 1–3 个英雄级复合运镜，其余镜头用清楚、稳定的基础运动建立可读性。

每个复合运镜写清：

- 参与同步的单一运动。
- 主体在画面中的尺寸变化规则。
- 背景、透视和前景的预期效果。
- 起点、终点、速度曲线和稳定方式。
- 为什么该镜头在此处成立。

Dolly Zoom 必须明确“物理推拉方向与变焦方向相反，主体大小近似不变，背景透视剧烈拉伸或压缩”。不要把普通推镜加数字放大误标为 Dolly Zoom。

### 8. 编写镜头表和 Seedance 提示词

每个镜头至少包含：

| 字段 | 内容 |
|---|---|
| 编号/时间 | 镜头号、起止时间、时长 |
| 叙事功能 | 本镜新增的信息或情绪变化 |
| 画面 | 主体、动作、前景、中景、背景 |
| 景别/角度 | 广角、中景、近景、特写、微距；平视、俯拍、仰拍等 |
| 镜头感觉 | 焦段感、景深、透视、呼吸感 |
| 运镜 | 静态、跟踪、手持或复合运镜的完整操作 |
| 灯光/色彩 | 光源方向、光质、时间和综合色 |
| 情绪/表演 | 可见动作、微表情与情绪进展 |
| 声音 | 环境声、拟音、对白、音乐节点 |
| 连续性 | 角色、道具、轴线、动作和光线衔接 |
| 差异说明 | 相对前镜的至少两项明确变化 |

把 Seedance 提示词写成可见、可拍、按时间执行的语言。先写共享锁定，再写每镜时间轴；明确每个 `@图/@视频/@音频` 的角色，不使用“参考这个感觉”等模糊指代。

### 9. 组装 16:9 制作板

严格按照 `references/production-board-spec.md` 组装。优先使用可准确排版的演示文稿、HTML/CSS 或绘图工具；图像模型主要生成角色、环境和故事板画面，不让图像模型承担大量中文小字。

将完整技术说明放在伴随镜头表中，制作板只保留一眼可读的短标签。任何生成的参考图必须与镜头表编号一致。

### 10. 质量复核

交付前检查：

- 八个镜头是否各自提供新空间、新信息或新情绪。
- 人物身份、服装结构、配饰和关键道具是否一致。
- 环境俯视图、C1–C8 机位和故事板是否互相对应。
- 复合运镜是否物理可理解、叙事有动机、没有堆叠过多。
- 日照、色温、天气和阴影是否形成可信时间过渡。
- 音频节点是否支持剪辑节奏，而非与动作脱节。
- Seedance 素材数量、时长和引用方式是否符合本地手册快照；执行前若可联网，核对平台最新限制。
- 所有提示词是否通过政策检查。
- 16:9 版面是否在缩略图中仍能看出层级，文字是否准确无乱码。

## 输出顺序

按以下顺序输出，避免先给散乱提示词：

1. 项目摘要、共享创意指导与统一规则卡。
2. 角色与视觉一致性卡。
3. 环境、动线和机位计划。
4. 八镜头表。
5. 灯光/情绪时间线、关键词、音频和摄影笔记。
6. Seedance 共享锁定与逐镜提示词。
7. 16:9 制作板成品或明确的待渲染版式稿。
8. 相似度、连续性和政策自检结论。
