# Runway 内容政策 · 提示词敏感规避指南

> 来源：[Runway Usage Policy](https://help.runwayml.com/hc/en-us/articles/17944787368595-Runway-s-Usage-Policy)（最后更新 2026-03-06）
> 本文件用途：作为本项目写提示词、分镜脚本时的**敏感内容规避指导**。所有分镜文件生成前应参考此文件校验。
> 性质：政策摘要 + 实操改写规则，均为内容合规性提醒。Runway 使用自动系统与人工审核相结合检测违规输入输出。

## 一、官方禁止类目（摘要）

### 1. 儿童安全（Children's Safety）
- 描绘、促成或宣传儿童性虐待，或对儿童性化的内容
- 任何涉及儿童性虐待材料（CSAM）会被上报 NCMEC 并永久封号
- 促成未成年人诱骗行为，包括生成冒充未成年人的内容
- 描绘儿童遭受虐待，或未成年人参与有害或危险行为
- 当画面中出现儿童时，Runway 对其他类目的审核标准会**更加严格**

### 2. 暴力与血腥（Violence & Gore）
- 描绘、促成或宣传恐怖主义与暴力极端主义
- 图像化的暴力，或煽动暴力的内容
- 血腥画面：断肢、斩首、残害、暴露的器官/骨骼/肌肉
- 描绘或宣传虐待动物

### 3. 性相关内容与裸露（Sexually Explicit Content & Nudity）
- 色情露骨内容，包括情趣用品与某些恋物内容
- 成人裸露
- 制作或修改未经同意的亲密影像（NCII）的尝试
- 部分情况下，性暗示内容（含内衣、蕾丝等）也会被限制

### 4. 仇恨言论、骚扰与自残（Hateful Conduct, Harassment, and Self-Harm）
- 基于受保护属性（种族、民族、宗教、性别、性取向等）非人化他人或宣扬歧视/暴力
- 骚扰、霸凌、恐吓、诽谤或辱骂他人
- 描绘、促成或宣传自残，包括饮食失调

### 5. 可能侵犯他人权利的内容（Rights of Others）
- 未经他人许可使用其图像、视频、音频
- 危及他人隐私的内容
- 可能侵犯知识产权的内容
- 模仿**在世知名艺术家**风格的尝试

### 6. 误导性内容（Misleading Content）
- 用于欺诈、行骗或故意误导他人
- 冒充个人或实体，或虚假声明与某人/某机构的关联

### 7. Runway Characters 与 Game Worlds 额外政策
- 基于 18 岁以下人物面部或声音创建的角色
- 以未成年人为目标用户的角色或游戏（包括面向儿童的叙事元素或视觉风格）
- 提供医疗、法律、财务建议或模仿专业治疗/咨询的角色或游戏

## 二、本项目实操规则（提示词改写指南）

我们做的是高强度对抗类 CG 脚本，所以主要冲突点集中在**暴力与血腥**，偶尔会撞到**性暗示**（角色原设计）。下面是写提示词时的落地规则：

### 规则 A · 避免人体直接受击的具体描写
**不要写的词**：
- 撕碎 / 撕裂（对人体） / 穿透人体 / 戳穿 / 刺穿 / 砍开人体
- 鲜血、血液、血溅、血迹、血泊、断肢、残肢、头颅、内脏、骨骼暴露
- 被打飞的具体人物（尤其带"重重摔在地上""骨骼断裂"这类后果）
- 尸体、死亡、倒下不动

**改写方向**：
- 把"怪物攻击→人体受伤"改成"怪物攻击→非人物体毁坏+冲击波扫过"
  - 原：尾巴扫过，队员被撕成两半 → 改：尾巴扫过，路边空车被卷起旋转抛飞
  - 原：鞭刺穿透身体 → 改：鞭刺劈开车辆引擎盖，金属外壳崩开
- 把"人员倒下"改成"人员被气浪掀翻 / 装备脱手飞出 / 盾牌滚落"
  - 让观众通过**装备飞出**间接感受冲击，不直接呈现人体
- 把"鲜血"替换成"火花、绿色能量、黑色粒子、碎屑、粉尘"
- 把"断肢翻转"改成"装甲碎片翻转、翅膀骨架断裂、尾巴断面露出金属结构"——**非生物属性**的断裂可以保留

### 规则 B · 怪物/机甲/非人目标可保留破坏细节
Runway 对"非人类、无机质、装甲、能量体"的破坏相对宽容。
- 女皇终结者属于魔化生物 + 甲壳装甲，可以被砍断翅膀、劈碎胸甲、核心爆裂
- 写"绿色能量爆散""装甲崩裂""翅膀断裂耷拉"都比"鲜血飞溅"安全
- 但仍避免写"断头""内脏外露"等极端词汇

### 规则 C · 人类角色（灵狐、SWAT、平民）只能受到**间接冲击**
- 灵狐可以闪避、跳跃、翻滚、擦伤
- 平民只能奔逃、掉东西、被气浪推开，不能被怪物直接抓到或击打
- SWAT 小队只能被气浪整体掀翻，装备散落；不写伤亡结果
- 段末不出现人类伤亡画面，用"街道空无一人 / 丢下的物品"来暗示

### 规则 D · 儿童零出镜
参考原则 1 的"更严格标准"。
- 不要写"小女孩""小男孩""儿童""婴儿""孩子"
- "推婴儿车的母亲"这种描写也建议替换为"年轻女性" / "行人"，不提婴儿车
- 如果要展现"生活感"，用上班族、学生、情侣、老人、游客即可

### 规则 E · 灵狐角色设计的性暗示风险
灵狐原设为黄色小礼服 + 黑色网袜 + 高跟靴，踩在"性暗示内容"的边缘。
- **不要**用：挑逗、撩人、诱惑、暴露、胸部、臀部、大腿内侧、紧身贴合、若隐若现
- **可以**用：军装式、制服、网眼长袜、系带短靴、制服下摆、侧风吹动头发、冷峻神情、专业姿态
- 镜头语言上避免**从下往上拍腿部**、**从后方拍臀部**、**特写胸部/胯部**
- 如果需要腿部动作（滑步、滑铲、空翻），聚焦**动作线条**而不是**身体曲线**

### 规则 F · 武器描写原则
- 真实现代武器（狙击枪、加特林、SWAT 突击步枪）可以写，不违反政策
- 避免把武器与极端意识形态、恐怖组织、历史暴行绑定描述
- 不写"指向镜头开枪""对准人头扣扳机"这类直接威胁观众视角的描写
- 开火的后果（子弹命中非人目标 / 金属火花 / 装甲涟漪）可以详写

### 规则 G · 知名 IP 与真人风险
- 本项目角色"灵狐""女皇终结者"来自《穿越火线》，直接使用 @ 参考图 + 静态特征描述，不提 IP 名称、不提"CF""穿越火线""腾讯"
- 不模仿在世艺术家风格（如"在世电影导演名字+风格"）
- 电影质感参考可以写"电影感、写实质感、类似夜景与城市氛围"这类**通用描述**，避免点名

### 规则 H · 触发拒绝后的快速自救
如果提示词被拒绝，按以下顺序排查：
1. 是否出现规则 A 的禁止词 → 替换成非人体破坏
2. 是否出现儿童元素 → 移除或替换
3. 是否出现性暗示词 → 替换成专业/中性词
4. 是否出现真实组织名、品牌、人物名 → 改为通用描述
5. 仍被拒 → 拆镜，把高冲击元素分散到多个短镜

## 三、本项目当前状态自检清单

写完每一段分镜后，按此清单过一遍：

- [ ] 没有描写人体直接受伤、流血、断肢、死亡
- [ ] SWAT / 平民只出现"被气浪掀翻 / 装备脱手 / 奔逃"等间接冲击
- [ ] 没有儿童、婴儿、未成年人元素
- [ ] 灵狐的身体描写聚焦制服、发型、动作，而非身材曲线
- [ ] 没有从下往上拍腿 / 特写胸胯 / 身体贴近镜头的暗示性构图
- [ ] 没有出现"穿越火线""CF"等 IP 字样
- [ ] 没有出现真实知名人物或在世艺术家的名字
- [ ] 女皇的破坏对象是"空车 / 玻璃 / 招牌 / 装甲",而非人体
- [ ] 斧头、狙击枪的使用对象是女皇（非人生物）或无机物
