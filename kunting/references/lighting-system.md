# 光线系统

- 优先选择场景内合理来源：窗光、招牌、顶灯、走廊灯、车灯、路灯、屏幕或天光。确定来源后必须写方向、覆盖区和禁光区，不能只写“有来源”。
- 先从黑位和未照亮区域建立构图，再用方向性光照亮叙事中心；不要先把整个空间平均提亮。非叙事墙面、天花板、无关货架或机器可明确设为禁光区。
- 主体、背景与视觉锚点不得处于相同曝光层。常规张力场景让背景比人物低约一至两档；需要图形化时可让背景进一步下降，但人物眼神与手势仍需可读。
- 局部硬亮部可以只占画面约 3%–10%，例如一条窗光、一块桌面、一盏实景灯或一个高反射物件；亮部要集中，不把每盏灯和每个金属面都点亮。
- 人脸可比背景高半档至一档，或以轮廓光保留形体；不要把“黑”理解成看不清。
- 硬侧光适合明确对峙、午后窗影或暴露状态；柔顶光适合等待、疲惫和表面平静。
- 实景光可以在背景形成色点或方向线，但不让无关霓虹填满所有夜景。
- 冷暖混合光必须有来源：例如冷窗光对暖台灯，而不是泛化橙青调色。
- 强光比用于信息不对等、空间分割、表演性或心理转折；普通交易与日常等待仍可使用明确的方向光和背景降档，不等于柔光铺满房间。
- 除非用户明确要求剪影，眼睛、肤色、手部和服装主色必须落在可读中间调；紧张感来自方向、遮挡和关系，不来自欠曝。
- 白天外景可用硬日光与天空填充形成清楚边缘；室内可让窗光或实景灯形成局部硬影，但必须保留人物面部信息。
- 避免为“犯罪感”自动增加烟雾、体积光、青绿色顶灯、湿地反光或大面积黑角。
- 避免把所有顶灯同时点亮、让每面墙都有补光、用柔和环境光填平阴影边界；这些做法会把画面推向自然主义商业写实。
