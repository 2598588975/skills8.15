# Seedance 分镜脚本生成器

把一段**剧情文字**（剧本、小说桥段、动作描述、广告脚本、宣传片文案、一句话创意）转写成 **Seedance / 即梦** 文生视频可直接喂入的**分镜脚本**：先定全局影像风格，再按秒拆成字段清晰的逐镜脚本。

输出风格对标专业的影视化分镜文案——精确到秒、画面明确、运镜明确、情绪可演、声音和转场可剪辑、画面可拍。

## 为什么是这个结构

Seedance 的提示词遵循 **主体 + 动作 + 场景 + 光影 + 镜头语言 + 风格** 的骨架，模型很擅长在清晰输入上做扩展。单条视频通常 **5s 或 10s @ 24fps**；多镜头要靠**显式的切换/衔接提示**（如「无缝切至」「镜头切换」），切镜后**要重新交代新场景**。模型**不响应负向提示词**，所以「不要…」要改写成正向描述；脸部/人体/角色一致性这类**稳定性约束**写进风格头里能显著减少崩坏。

整套脚本因此分两层：**全局头**（一次性定调，所有分镜共享）+ **分镜时间轴**（逐镜的镜头与动作）。

## 输出模式路由

保留两种格式；先选一种，再完整执行对应规则。不要在同一份交付中混用两套镜头格式。

### 字段化分镜模式（默认）

用于通用 storyboard、shot list、广告/宣传片细化、即梦/可灵/Veo/Sora 等未指定生产规范的请求。继续使用本文件下方原有的 5/10 秒方案和 `画面 / 景别构图 / 运镜 / 情绪 / 台词旁白 / 声音 / 转场备注` 字段。

### Seedance 2.0 生产提示词模式

用户明确提出以下任一需求时，完整读取并执行 `references/seedance-v23-production-rules.md`：

- Seedance 2.0 成片执行稿、全片或多组视频提示词；
- 每组最多 15 秒、短漫剧密度、打戏拆镜或镜头数量硬门；
- 原台词与标点逐字保护、台词容量预检；
- `@资产`、状态资产、人物空间站位、跨组承接、角色音色；
- 真人写实、写实/风格化 3DCG、2D 的媒介化生产提示词。

生产模式的最终镜头使用“标题 + 单一自然段”，由 V2.3 负责分组、密度、空间、资产和自检；不要再套用字段化模板。普通单场短分镜仍走默认模式，不强制升级。

### 场景分段统一规则（附加模块）

用户要求“统一规则”“整体规则”“每个场景分别定调”“人物全程一致”“先规则后分镜”或给出类似 `{{Mixed 1}}` 的角色资产变量时，完整读取并执行 `references/scene-unified-rules-format.md`。

该模块不是第三种分镜格式，可以与字段化模式或 Seedance 2.0 生产模式组合。先按剧情顺序输出各场景段落的专属规则，再把人物身份、服装、动作流畅度、眨眼、色彩总原则、声音/BGM和文字合成等公共约束精简放在最下方；不要把同一条全局约束机械复制到每个场景。

### 兼容与优先级

1. 用户明确指定的输出格式优先；用户只说“分镜”时使用字段化默认模式，只说“Seedance 2.0 生产提示词”时使用 V2.3 模式。
2. 冲突时按“源剧本事实与用户硬约束 > 物理/空间/台词可承载性 > 当前模式规则 > 示例”处理。
3. V2.3 中的分析表、容量计算、状态账本和自检默认在内部完成，不泄漏到最终提示词。
4. 参考文件中的固定外部输出路径不适用于本整合版；默认在聊天中交付，用户明确要求文件时才写入当前工作区允许的交付目录。
5. 用户没有视觉资产库时允许建立临时 `@资产` 清单；不要在本 skill 内生成资产文生图提示词。
6. 用户提供的 `{{变量}}`、`@资产名`、角色编号和专有占位符逐字保留，不擅自改名、互换或合并。

## 工作流程（字段化默认模式）

1. **读懂剧情**：先把输入读成「谁、在哪、做什么、什么情绪、什么节奏」。先不急着写格式。
2. **判断是单镜片段还是多场景长剧本**：
   - **单场景 / 一段连续动作**（一镜到底或几次切换，总时长 ≤10s）→ 输出**一条** Seedance 分镜脚本。这是默认情形，也是质量最高的用法。
   - **多场景 / 长剧本**（出现明显的时间或地点跳转、多段对白、章节）→ 先按场景切分，**每个场景产出一条独立的 Seedance 分镜脚本**，并在每条前加 `### 场景 N · <一句话场景名>` 标题。每条仍各自 ≤10s。不要把跨场景的内容塞进同一条 10s 脚本里。
3. **定全局影像风格**（见下方模板的三个头）：从剧情的类型、年代、情绪反推镜头器材、色彩调性、情绪节奏。剧本没写的，按类型合理补全（科幻冷调、古装暖调、悬疑低照度…），但不要无中生有地改变剧情设定。
4. **拆分镜时间轴**：把这段动作拆成若干 beat，每个 beat 一个分镜，标注**时间区间**，让区间累加 ≈ 目标总时长（默认 ~10s；用户指定了就按指定）。每个分镜必须使用字段化格式，至少包含：`画面：`、`运镜：`、`情绪：`、`台词/旁白：`、`声音：`、`转场/备注：`。相邻分镜要能接上（动作的尾接下一镜的头）。
5. **自检**：时间轴是否连续不重叠？每镜是否都有画面、运镜、情绪、台词/旁白、声音和转场/备注？是否全程同一主体/服装一致？有没有把「不要 X」写成了负向提示（要改成正向）？

## 写好分镜的要点

- **字段化先行**：每镜必须分行写出 `画面：`、`景别/构图：`、`运镜：`、`情绪：`、`台词/旁白：`、`声音：`、`转场/备注：`，方便后续扩展成分镜表、shot list、AI 视频 prompt 或剪辑清单。
- **景别 + 运镜清晰**：景别（远景/全景/中景/近景/特写）和运镜（推/拉/摇/移/跟/升降/环绕/手持）要明确。这是 Seedance 最吃的镜头语言。完整词表见 `references/seedance-vocab.md`。
- **动作要连贯可拍**：写「右手闪电般探向腰间快拔枪套，拇指顺势扳倒击锤」这种有先后、有力学的动作链，而不是「他很厉害地战斗」。一个分镜聚焦一个核心动作 beat。
- **首尾相接**：上一镜的收尾动作，要能自然接到下一镜的起势，整段读下来像一条连续运动。多镜切换时用「无缝切至 / 镜头甩动跟至 / 切至」点明衔接方式。
- **正向代替否定**：模型不认负向词。「不要模糊」→「主体边缘锐利清晰」；「别变形」→「人体结构正常、比例自然」。
- **时长贴合 Seedance**：默认按 ~10s 排时间轴（也可 5s）。分镜数量随动作密度定，一般 5s 给 2–4 镜、10s 给 4–7 镜，别把太多动作硬塞进一镜。
- **保持剧情忠实**：补全的是镜头/光影/质感这些拍摄层信息，不要篡改人物、动作走向、结局等剧情设定。

更细的镜头/运镜/色彩/质感词表与更多范例，见 `references/seedance-vocab.md`，需要时再读取。

## 示例（单场景 · 一段动作戏）

**输入：**
> 黑暗仓库里，女杀手听见身后脚步，猛地转身，一脚踢翻挡路的铁桶，拔枪连开两枪撂倒两名追兵，硝烟中转身冲出门外。

**输出：**

```
【视觉基调】
变形宽银幕电影质感，仿 35mm 胶片摄影机 + 定焦镜头；手持跟拍为主，轻微抖动与动态模糊，强临场感。

【色彩与调影】
现代冷峻动作片美学；青橙对比色调，暗部偏冷蓝、火光与枪口焰偏暖橙；高对比低照度，胶片颗粒质感；侧逆光勾边，暗部保留细节，高光不过曝。

【情绪基调】
紧张凌厉，节奏短促爆裂，凸显以一敌多的危机感与利落的暴力美学，强调速度与精准。

【一致性约束】
始终为同一名女杀手，黑色紧身作战服与发型一致；人体结构正常、比例自然；面部清晰稳定不扭曲。

【画面内容】
分镜1 警觉转身（0–2s）
画面：女杀手背对镜头立于黑暗仓库，听见身后脚步骤然顿身，肩颈先动带动腰胯，猛地向左后方转身，发丝与衣摆甩出弧线，视线锁定来向。
景别/构图：中景，人物偏画面右侧，背后黑暗通道留出危险负空间。
运镜：手持跟拍，轻微抖动，随肩颈转动小幅甩动。
情绪：警觉、瞬间进入战斗状态，节奏骤然收紧。
台词/旁白：无。
声音：远处脚步声先到，衣料甩动声贴近镜头。
转场/备注：动作尾部接下一镜踢腿起势，保持同一角色服装和发型。

分镜2 踢翻铁桶（2–3.5s）
画面：转身惯性未尽，右腿凌厉扫出，一脚踢翻挡在身前的铁桶，铁桶翻滚撞地火星四溅，她借势压低重心拔枪出鞘。
景别/构图：全景，铁桶位于前景左侧，人物重心压低在画面中央。
运镜：镜头随身体快速甩动，低角度横移。
情绪：爆发、利落、以动作抢回主动权。
台词/旁白：无。
声音：铁桶撞地声、火星噼啪声、枪套摩擦声。
转场/备注：用铁桶翻滚方向引导到下一镜枪口横移。

分镜3 连开两枪（3.5–7s）
画面：双手稳握手枪贴脸瞄准，第一枪精准命中左侧追兵，枪口焰照亮面部；枪口顺势横移，第二枪撂倒右侧追兵，硝烟与弹壳在慢速气流中飞溅。
景别/构图：近景，枪口和面部形成双焦点，追兵只以模糊轮廓进入背景。
运镜：贴身横移，随枪口从左扫向右。
情绪：精准、冷静、危险逼近。
台词/旁白：无。
声音：两声枪响间隔短促，弹壳落地声进入下一镜。
转场/备注：硝烟作为转场遮挡，接下一镜突围。

分镜4 硝烟突围（7–10s）
画面：她不作停顿，压枪转身朝门口疾冲，穿过弥漫硝烟，逆光门框透入强光将身形勾成剪影。
景别/构图：中景，门框作为远处出口，人物剪影在中央向前冲。
运镜：后拉跟随，保持人物速度感。
情绪：紧迫、突围、危险尚未解除。
台词/旁白：无。
声音：急促脚步、呼吸声、门外风声渐强。
转场/备注：以逆光门框作收尾画面，可硬切到下一场景。
```

> 多场景长剧本：对每个场景重复上面这套结构，并在每份前加 `### 场景 N · <场景名>`，每份各自 ≤10s、各自带完整的三段头。
