# Negative Prompts

## 基础反向限制

每次至少使用这一组：

```text
不要商业广告感，不要海报排版，不要插画风，不要漫画风，不要普通网红摄影，不要时尚大片摆拍，不要赛博朋克，不要恐怖片氛围，不要杂乱背景，不要夸张表情，不要夸张动作，不要现代霓虹灯，不要塑料质感，不要过度磨皮，不要 AI 生成感，不要漂浮物体，不要畸形手指，不要错误透视，不要文字水印，不要 logo，不要斜拍，不要倾斜构图，不要荷兰角，不要歪地平线，不要斜向透视，不要建筑歪斜，不要可见竖线切开人脸，不要中轴实体线穿过人物身体，不要墙缝/门缝/柱子/标牌支杆压在脸部中央，不要整体发灰，不要证件照式正面站姿，不要僵硬全身居中摆拍
```

## 按问题补充

### 如果画面太像广告

```text
避免产品广告、品牌宣传照、商业橱窗大片、过度精修、闪亮新品质感、营销海报、标题字体、促销排版
```

### 如果画面太像插画或漫画

```text
避免插画笔触、漫画线稿、二次元、卡通比例、夸张五官、绘本插图、扁平矢量、概念设定图
```

### 如果画面太像网红写真

```text
避免自拍感、网红滤镜、摆拍笑容、浅景深糖水片、旅行打卡照、社交媒体封面、过度美颜、现代街拍
```

### 如果画面太呆板

```text
避免证件照式正面站姿、人物僵硬站在画面正中央、双手垂直无动作、直视镜头摆拍、单调正面平视、没有前景层次、没有动作瞬间、没有空间调度
```

### 如果画面不够对称或总是斜

```text
避免斜拍、倾斜构图、荷兰角、歪地平线、斜向透视、随手抓拍、相机左右倾斜、建筑线歪斜、门窗不水平、柜台不水平、主体偏离中心太远、左右道具失衡、消失点偏到画面边缘
```

### 如果中轴线切脸或切身体

```text
避免可见中轴实体线、竖线切脸、竖线穿过鼻梁、墙缝压在人脸中央、门缝切开头部、柱子穿过身体、标牌支杆穿过人物、地砖缝从脚下延伸到脸部、人物被左右镜像拼接感
```

### 如果画面发灰

```text
避免整体灰雾、低饱和灰调、脏绿色阴影、暗沉旧照片、雾霾感、灰色滤镜、曝光不足、死白天空、脏旧褪色、泥泞色彩
```

### 如果画面太乱

```text
避免随机杂物、凌乱背景、无序人群、过多装饰、拥挤构图、看不出中轴线、道具堆砌
```

### 如果画面太现代

```text
避免现代极简公寓、现代办公楼、LED 屏幕、智能手机、现代汽车、现代运动鞋、玻璃幕墙、冷白商业灯
```

### 如果画面太阴暗或恐怖

```text
避免恐怖片打光、血腥、惊悚、阴森废墟、脏污破败、强烈暗角、冷绿病态光、怪物化人物
```

### 如果画面有 AI 塑料感

```text
避免蜡像皮肤、塑料表面、过度锐化、HDR 过强、虚假胶片颗粒、质感糊成一团、手部错误、面部不自然、背景文字乱码
```
