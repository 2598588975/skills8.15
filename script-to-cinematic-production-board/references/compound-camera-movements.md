# 复合运镜库

复合运镜是两个及以上相机动作的同步组合。先确定叙事用途，再选择；八镜方案通常只用 1–3 个英雄级复合运镜。

## 基准：希区柯克变焦（Dolly Zoom / Zolly）

- 操作：物理推近 + 反向变焦拉远，或物理后拉 + 反向变焦推近，同步执行。
- 主体规则：主体在画面中的大小近似不变。
- 效果：背景透视剧烈拉伸或压缩，空间关系看似失真。
- 用途：认知冲击、恐惧、真相揭示、心理失衡。
- 避免：不要用数字裁切替代光学变焦；不要让主体尺寸明显漂移。

## 一、变焦 + 物理移动

### 1. 正向推变焦（Push + Zoom In）

- 操作：物理向前推进，同时向内变焦放大。
- 效果：主体快速放大，背景虚化收缩，压迫感上升。
- 用途：震惊、愤怒、对峙、关键物揭示、悬疑节点。

### 2. 正向拉变焦（Pull + Zoom Out）

- 操作：物理后退，同时向广角端拉开。
- 效果：人物快速缩小，环境迅速铺开。
- 用途：失落、离别、结局收尾、宏大环境展示。

### 3. 斜向希区柯克变焦（Diagonal Dolly Zoom）

- 操作：沿约 45° 斜线推拉，同时反向变焦。
- 效果：空间扭曲更柔和，增加侧向视差和悬疑感。
- 用途：剧情短片、情感混剪、角色察觉异常。

## 二、环绕 + 多轴运动

### 4. 螺旋环绕（Orbit + Crane）

- 操作：匀速环绕主体，同时缓慢上升或下降。
- 效果：立体展示主体，空间层次和仪式感增强。
- 用途：人物高光、地标、产品英雄镜头、婚礼、氛围人物。

### 5. 后环绕 + 缓慢拉远

- 操作：从人物正面环绕到背后，同时持续后拉。
- 效果：从情绪近观过渡到环境揭示，强调宿命或孤立。
- 用途：告别、伤感转折、悬疑结尾。

### 6. 环绕 + 微推

- 操作：环绕主体时同步小幅前推。
- 效果：空间在变化，画面持续收紧。
- 用途：冲突前夕、对峙、产品细节逐步揭示。

## 三、穿行 + 推拉/摇移

### 7. 前景穿行推镜

- 操作：锁定主体，从门框、栏杆、树枝或缝隙中穿过并前推。
- 效果：前景高速划过，主体相对稳定，形成窥视感和纵深。
- 用途：探店、街拍、剧情转场、风景穿行、隐秘观察。

### 8. 横向弧移 + 微拉

- 操作：沿平滑弧线横移，同时轻微拉远。
- 效果：比直线平移更有空间弧度，人物与背景关系逐渐展开。
- 用途：人物边走边叙事、关系展示、产品跟随。

### 9. 俯冲前推

- 操作：高位向前飞行，同时镜头向下俯仰并降低高度。
- 效果：从宏观全景快速落到地面主体。
- 用途：开场、地标、战场到人物、规模转细节。

## 四、跟随 + 推拉/俯仰

### 10. 跟推（Follow + Push）

- 操作：跟随人物行进，同时缓慢前推收紧。
- 效果：从中景过渡近景，情绪持续加压。
- 用途：独白、赶路、紧张升级、走心段落。

### 11. 跟拉（Follow + Pull）

- 操作：跟随人物，同时后拉扩大环境。
- 效果：人物相对缩小，环境支配画面。
- 用途：压抑、自由、离开、环境吞没个体。

### 12. 45° 斜跟 + 微俯仰

- 操作：从侧后方约 45° 跟拍，配合轻微上下俯仰。
- 效果：避免平直跟拍，增加步态和空间变化。
- 用途：最通用的人物行进、商业广告和剧情过渡。

## 五、旋转/失衡 + 推拉

### 13. 滚镜推拉（Roll + Dolly）

- 操作：相机绕光轴滚转，同时物理前推或后拉。
- 效果：地平线旋转，空间秩序瓦解。
- 用途：梦境、精神崩溃、时空扭曲、极端转折。

### 14. 荷兰角 + 缓慢推镜（Dutch Tilt + Push）

- 操作：保持倾斜地平线，同时缓慢前推。
- 效果：持续不安、失衡和压迫。
- 用途：悬疑、恐怖、冲突、危险预感。

## 六、转场复合运镜

### 15. 高速甩镜 + 轻微拉远（Whip Pan + Pull）

- 操作：高速横向甩动，甩动阶段同步小幅后拉。
- 效果：运动模糊掩盖剪切，前后镜头可无缝连接。
- 用途：短视频、Vlog、混剪、地点或服装切换。

### 16. 摇镜 + 缓慢拉远（Pan + Dolly Out）

- 操作：横向摇镜交代关系，收尾阶段同步后拉。
- 效果：自然扩大空间并结束段落。
- 用途：群像关系、环境交代、段落收尾。

## 快速选择

- 氛围：螺旋环绕、前景穿行推镜、斜向 Dolly Zoom。
- 人物情感：跟推、跟拉、后环绕拉远。
- 悬疑失衡：经典 Dolly Zoom、荷兰角推镜、滚镜推拉。
- 转场：甩镜拉远、摇镜拉远。
- 产品：螺旋环绕、环绕微推、俯冲前推、微距跟推。
