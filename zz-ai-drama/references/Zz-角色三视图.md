# Zz-角色三视图

## 核心目标

根据用户提供的角色参考图，生成可供 3D 建模、角色绑定、动画制作和影视资产生产使用的工业级正交视图（Orthographic Views）。

参考图是角色唯一视觉标准。所有视图必须呈现同一角色、同一套资产和同一骨架姿势，只改变正交观察方向。

默认输出：

- Front：正面
- Left：角色左侧
- Right：角色右侧
- Back：背面

可选输出：

- Top：顶部
- Bottom：底部

只有用户明确要求，或角色头顶、鞋底结构对建模不可缺少时，才加入 Top 与 Bottom。

## 输入门槛

1. 必须获得至少一张清晰的角色参考图，再执行生成。
2. 若没有参考图，停止生成，并只请求用户上传参考图。
3. 优先使用完整全身、无遮挡、能辨认鞋底与服装轮廓的参考图。
4. 必须实际查看参考图，识别人物身份、骨骼比例、发型、服装层级、配饰、材质和左右不对称特征。
5. 若多张参考图中的人物或服装版本冲突，请用户指定唯一主参考图。
6. 若侧面、背面、头顶或鞋底不可见，不得虚构复杂结构。优先请求补充视图；用户允许保守补全时，只能延续可见结构、材料和制造逻辑，并保持装饰最小化。

## 执行流程

1. 查看参考图，建立角色不可变身份与比例锚点。
2. 记录左右不对称项：发缝、刘海、耳饰、护具、袖型、腰饰、武器挂点、疤痕和纹样。
3. 选择统一的建模基准姿势，默认使用自然 A-Pose。
4. 调用可用的图像生成或图像编辑能力，并在每轮生成或修改时持续携带原始参考图。
5. 在同一画布生成 Front、Left、Right、Back；按需加入 Top、Bottom。
6. 检查人物身份、比例、投影、轮廓、关节点、服装连续性、左右关系、标签和裁切。
7. 发现问题时定向修正；不得因修复一个视图而破坏其他视图的比例和身份。
8. 默认只交付最终图像；仅在缺少参考图、隐藏结构无法确认或工具受限时简短说明。

## 资产一致性锁定

所有视图必须严格保持：

- 同一人物身份、年龄感、性别呈现、人种特征与面部骨相。
- 同一头身比、头围、肩宽、胸廓、腰线、骨盆、四肢长度、手脚尺度。
- 同一发际线、发型结构、发色、发长、发饰与发束数量。
- 同一服装轮廓、层级、长度、材质、颜色、纹样、接缝和闭合方式。
- 同一鞋履、首饰、护具、腰带、挂件与其他配饰。
- 同一线条、纹理密度、材质表现和艺术风格。

严禁换脸、年龄漂移、体型漂移、头身比变化、四肢忽长忽短、服装换款、发型变化、配饰丢失或画风漂移。

## 正交投影标准

- 使用真正的正交投影（orthographic projection），平行线保持平行。
- 禁止透视收缩、广角变形、近大远小和镜头畸变。
- 禁止俯拍、仰拍、三分之四视角、动态倾斜和夸张构图。
- Front 与 Back 的身体中轴线垂直于画面。
- Left 与 Right 使用严格九十度侧视，鼻尖、胸廓、骨盆、膝盖和足尖处于正确侧向关系。
- 所有视图使用相同投影尺度，不得单独缩放头部、身体或配饰。
- 人物脚底对齐同一水平基线，头顶对齐同一高度线。
- 眼线、肩峰、肘、腕、腰、胯、膝、踝等关键关节点在对应视图中保持水平对齐。
- 不使用透视地面、消失点、景深或空间雾化。

## 基准姿势

默认采用自然 A-Pose：

- 身体直立，脊柱保持中立，骨盆不侧倾。
- 头部端正，视线水平，面部使用自然中性表情。
- 双臂从躯干向外自然分开，肘部伸展但不锁死。
- 双手自然伸直，手指适度分开，手掌朝向保持一致。
- 双腿自然分开，膝盖伸展但不反弓。
- 双脚平行朝前，脚掌完整着地，左右承重均匀。
- 不使用叉腰、屈膝、迈步、扭胯、耸肩或动态姿势。

所有视图必须保持完全相同的骨架姿势。不得为了填补空白或减少遮挡而改变手臂角度、脚距、头部朝向和站立高度。

## 身体完全展开与无遮挡

- 从头顶、发梢到鞋底全部可见，四肢、手指和脚部不得被画布裁切。
- 双臂与躯干保持足够间距，以便看清腋下轮廓、袖缝和腰侧。
- 双腿保持足够间距，以便看清内侧轮廓、裤裆或裙装结构与鞋履。
- 不允许武器、披风、长发、宽袖、挂件遮挡身体主要轮廓和关节点。
- 参考图中存在武器时，主正交图默认单独移出展示，不让角色手持。
- 长发、披风或宽大衣摆遮挡背部时，保留主视图的真实外观，并增加一个小型“无遮挡结构辅助图”，将遮挡层以外移或半透明轮廓表示；不得改变主视图资产。
- 严格侧视中不可避免的肢体重合不得通过改变骨架姿势解决；必要时添加独立手臂、手部或腿部辅助轮廓。

## 各视图标准

### Front

- 面部、胸骨、肚脐、骨盆中心和双脚中线保持在同一垂直轴。
- 左右肩、肘、腕、胯、膝与踝保持合理对称；角色固有不对称设计除外。
- 完整呈现正面服装层级、门襟、腰部结构和鞋面。

### Left

- 表示从角色左侧观察到的严格侧视图，不表示画面左侧。
- 鼻、下颌、后脑、胸廓、背部、骨盆、膝与足部轮廓形成真实侧向厚度。
- 准确展示角色左侧独有的耳饰、护具、腰饰和服装结构。

### Right

- 表示从角色右侧观察到的严格侧视图，不表示画面右侧。
- 不得直接镜像 Left；必须保留右侧独有的发束、配饰、纹样和装备。
- 与 Left 使用完全相同的身体比例、姿势和投影尺度。

### Back

- 后脑、后颈、肩胛、脊柱、骨盆中心和双脚中线保持垂直对齐。
- 完整呈现背部接缝、服装闭合、腰后结构、披风固定点、后摆和鞋跟。
- 所有从正侧面延伸到背面的腰带、滚边、纹样和配饰必须连续。

### Top（可选）

- 从角色正上方垂直观察，不带俯视透视。
- 展示头顶发旋、发缝、肩宽、前后厚度和顶部装备轮廓。
- 与其他视图使用同一正交比例基准。

### Bottom（可选）

- 从角色正下方垂直观察，不带仰视透视。
- 重点展示鞋底轮廓、底纹、鞋跟、衣摆底面和下方装备结构。
- 不擅自增加参考图未提供的鞋底花纹或隐藏部件。

## 左右与不对称规则

- 以角色自身方向定义 Left 与 Right，不以观看者方向定义。
- 发缝、刘海、耳环、护肩、护腕、腰包、挂件、武器鞘和服装纹样必须准确落在对应一侧。
- 成对配饰保持数量、尺度和高度一致。
- 单侧配饰不得在相反侧重复出现。
- 参考图无法确认左右归属时，先请求用户确认；不得随意镜像。

## 光照与背景

- 使用纯白背景。
- 使用完全均匀、无方向性的柔和漫射照明。
- 禁止地面阴影、投射阴影、接触阴影、环境遮蔽阴影和轮廓阴影。
- 禁止景深、焦外虚化、暗角、辉光、体积光、反射背景和环境色污染。
- 保留服装与材质自身的基础色和必要纹理，但避免强高光与明暗塑形遮蔽结构。
- 背景不得出现地平线、网格、场景、道具、装饰、纹理或渐变。

## 标签与对齐辅助

- 每个主视图下方使用准确英文标签：Front、Left、Right、Back。
- 可选视图使用标签：Top、Bottom。
- 标签大小、字重、基线和间距保持一致。
- 可使用极细、浅灰的水平对齐辅助线标记头顶、下巴、肩、肘、腕、胯、膝、踝与脚底。
- 辅助线不得穿过或遮挡角色主体；默认置于人物之间或版面边缘。
- 不加入与建模无关的长段说明、海报标题、角色台词或装饰文字。

## 标准版式

- 使用横向大画布。
- 默认从左到右排列：Front、Left、Right、Back。
- 四个主视图等高、等比例、等间距，并对齐同一脚底基线。
- 加入 Top、Bottom 时，将两个可选视图放在独立辅助区域，不缩小或挤压四个主视图。
- 保留足够安全边距，发梢、手指、衣摆、配饰和鞋底不得跨区或裁切。
- 画面只展示角色正交资产与必要标签，不生成拼贴照片、概念海报或剧情构图。

## 默认生成指令

根据所附角色参考图，生成用于 3D 建模、角色绑定、动画制作和影视资产生产的工业级角色正交视图。参考图是角色唯一视觉标准，严格保持同一人物身份、面部骨相、年龄感、肤色、头身比、身体比例、发型发色、服装结构、鞋履、配饰、材质、颜色、纹样和艺术风格。采用统一自然 A-Pose，身体直立，头部端正，双臂自然展开并离开躯干，双腿自然分开，双脚平行，四肢与手指完整可见。使用真正正交投影，无透视、无近大远小、无镜头畸变。横向画布从左到右排列 Front、Left、Right、Back，全部等高、等比例、脚底对齐、关节点水平对应；Left 与 Right 按角色自身方向定义，禁止简单镜像。背景纯白，完全均匀漫射照明，无地面阴影、无投射阴影、无接触阴影、无环境遮蔽、无景深、无暗角、无辉光、无场景。严禁换脸、比例漂移、姿势变化、服装变化、配饰丢失、左右颠倒、三分之四视角、透视变形、遮挡、裁切、额外人物、剧情背景、水印和签名。仅在用户明确要求时加入 Top 与 Bottom。

## 生成后质检

交付前逐项检查：

- 是否包含 Front、Left、Right、Back，并按规定顺序排列。
- 用户要求 Top、Bottom 时是否完整加入，未要求时是否保持简洁。
- 所有视图是否为同一人物、同一年龄、同一体型和同一套资产。
- 是否采用真正正交视角，而非三分之四视角、俯拍、仰拍或透视摄影。
- 头顶、下巴、肩、肘、腕、胯、膝、踝和脚底是否跨视图正确对齐。
- 各视图的头身比、肩宽、躯干长度、四肢长度和手脚尺度是否一致。
- 所有视图是否保持完全相同的 A-Pose、手势、脚距和站立高度。
- Left 与 Right 是否按角色自身方向定义，并保留真实不对称信息。
- 正面、侧面和背面的服装接缝、腰带、纹样、发型与配饰是否连续一致。
- 人物、四肢、手指、发梢、衣摆和鞋底是否完全可见且无遮挡、无裁切。
- 是否存在多余肢体、错误手指数、关节反折、身体粘连或服装穿模。
- 背景是否纯白，且完全没有阴影、景深、地平线、场景和装饰。
- 标签是否准确、清晰、位置统一。

任一关键项不合格时，继续定向修正，不得把透视错误、比例漂移、左右颠倒、视图不一致、遮挡或裁切的图片作为最终结果。

## 安全边界

- 未成年角色保持符合年龄的原始外观和服装，严禁性化。
- 武器从角色身上移出并作为静态资产处理，不表现攻击、伤口或血液。
- 不将普通角色替换成现实公众人物或受版权保护角色。
